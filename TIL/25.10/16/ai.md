# RNN과 LSTM

### 순차적 데이터
- 순서에 의미가 있는 모든 종류의 데이터
- 특징
    - 순서가 중요
    - 장기 의존성
    - 가변 길이
- 대표적인 예시
    - 자연어, 시계열 데이터

- MLP는 이걸 처리할 수 가 없음

## RNN

- 순환 신경망
- 순서가 있는 데이터를 처리하기 위해 고안된 인공 신경망
- 과거의 정보를 기억하고, 기억한 정보를 활용해 현재의 데이터를 해석

- CELL이 입력 데이터와 과거의 데이터를 섞어서 새로운 데이터를 만들어냄

### RNN - CELL
- 과거의 정보와 현재의 입력 데이터를 섞어서 새로운 데이터를 만들어내는곳
- 과거의 정보를 담아두는 곳이 바로 은닉상태

- 동작 방식
    - 셀은 두가지 데이터를 입력 받음
        - 현재 데이터
        - 이전 셀의 은닉 상태
    - 셀 내부에서 두가지 데이터를 조합하여 새로운 은닉 상태를 만듦
    - 새로운 은닉 상태는 두곳으로 전달됨

- 입력 데이터와 은닉 상태를 조합하는 방법에 대해서 살펴보자
- 각 입력데이터와 은닉 상태의 영향력을 나타내는 가중치가 존재
    - 입력 가중치: 입력 데이터의 영향력
    - 순환 가중치: 이전 기억의 영향력
    - 초기에 해당 값은 랜덤으로 설정됨

- 입력 데이터와 은닉 상태 조합의 방식
    - 셀은 두가지 데이터를 그대로 받지 않고, 각자의 가중치를 곱해 중요도를 반영
    - 두 정보를 합침
    - 합쳐진 정보를 활성화 함수에 넣어 압축
    - 새로운 은닉 상태를 다음 셀로 전달

- 사실 셀은 하나다.
    - 압도적인 효율
        - 입력 데이터가 아무리 길어도, 학습시킬 가중치 세트가 하나임
        - 모델이 매우 가볍고 효율적
    - 좋은 일반화 성능
        - 각 셀이 정해진 순서에 따른 데이터를 학습하는 것이 아님
        - 어떤 위치의 단어든 이전 기억과 조합하는 일반적인 방법을 학습

### RNN 학습 방식
- RNN이 학습하는 과정
    - 순전파
        - 우리가 배웠던 과정을 그대로 진행
        - 랜덤하게 초기화된 가중치를 사용
    - 오차 계산
        - 각 문제에 맞는 채점 기준에 맞춰 오차를 계산

    - 역전파
        - 정확히는 BPTT

        1. 최종 오차의 영향력을 역순으로 추적, 가중치가 오차에 미친 영향력을 구함
        2. 셀에는 은닉 상태의 입력 데이터의 가중치가 존재, 해당 시점의 입력데이터의 가중치가 오차에 미치 영향력을 구함
        3. 해당 시점의 최종오차가 은닉 상태가중치와 입력 데이터 가중치로 적절하게 나뉘면 은닉 상태 가중치의 오차를 이전 셀로 넘긴다.
        4. 2~3번 과정을 첫번째로 시점에 도달 할때까지 반복한다.
        5. RNN은 모든 시점에서 동일한 가중치를 사용하기 때문에 모든 시점의 가중치들을 합산하고, 이를 학습률과 오차가 줄어드는 방향으로 가중치를 업데이트

### RNN 한계
- 기울기 소실 문제
    - 이전정보의 책임 + 현재 시점의 책임으로 오차가 나눠지면서 뒤로 갈수로 오차 정보가 거의 전달되지 않음
    - 결국 오래된 정보에 대해서 학습이 제대로 이루어지지 않음
    - 장기 의존성 문제

## LSTM
- 이름 그대로 장단기 기억
- RNN의 한 종류로, 기종 RNN의 장기 의존성 문제를 해결하기 위해 설계됨
- 셀상태와 게이트라는 독자적인 구조를 도입하여 문제를 해결

- 은닉상태 + 셀 상태로 2가지 정보 전달 통로를 활용
- 셀 상태는 장기 기억을 전달하는 통로
- 셀 상태는 게이트를 활용하여 장기 기억을 전달할지, 삭제할지를 결정

### 구성요소
- 셀상태
    - 장기 기억 데이터를 전송하는 통로
    - 기존 RNN의 은닉 상태와는 다르게 덮어쓰기를 하지 않고, tanh 함수를 통과하는 드으이 복잡한 변환이 일어나지 않음

- 게이트
    - 장기 기억 통로일뿐인 "셀 상태"를 실질적으로 컨트롤하는 중요한 역할
    - 어떤 정보를 기억/망각/사용할지를 스스로 학습
    - 게이트 종류
        - 망각
        - 입력
        - 출력

### LSTM - 게이트
- 셀 상태를 실질적으로 컨트롤하는 중요한 역할
- 어떤 정보를 기억/망각/ 사용할지를 스스로 학습하여 결정
- 게이트의 작동 원리
    - 모든 게이트는 시그모이드 함수를 활용
        - 0: 게이트를 완전히 닫아 정보를 차단
        - 1: 게이트를 완전히 열어 모든 정보를 통과
        - 0.5: 게이트를 절반만 열어 정보의 50%만 통과
        - 시그모이드 활용 이유: 흐름을 조절하기에 적합한 범위를 출력

- (이전 시점의 단기 기억 + 현재 시점의 새로운 정보) * 각 게이트의 가중치의 값으로 게이트를 얼마나 열지를 결정


#### 망각 게이트
- 과거의 기억에서 어떤걸 지울까를 결정하는 게이트
- 불필요한 장기 기억을 제거하는 역할
- 작동 방식
    - 이전 시점의 은닉 상태와 현재시점의 입력을 하나의 벡터로 합침
    - 망각 게이트의 가중치와 생성한 벡터를 곱합
        - 현재 상황을 고려할 때, 장기 기억이 얼마나 중요한가를 평가하는 과정
    - 시그모이드 함수를 통과시키면서 "망각벡터"가 생성
    - 그리고 이 값을 셀 상태 * 망각 벡터를 통해 셀 상태를 선택적으로 지움

#### 입력 게이트
- 새로운 정보 중 어떤것을 셀 상태에 저장할까를 결정하는 게이트
- 중요하다고 판단되는 정보만 선별하여 기억을 업데이트함
- 작동방식
    - 업데이트 백터 생성 & 추가할 정보 생성
    - 그리고 이값을 추가할정보*업데이트 벡터를 통해 셀 상태에 업데이트

### 출력 게이트
- 셀 상태의 모든 정보 중에서 예측에 필요한 정보만 선별하여 외부로 내보내는 역할
- 셀의 최종 결과를 결정하는 역할
- 작동방식
    - 출력 백터 생성
    - 셀상태*출력백터를 통해 중요한 데이터만 출려

#### LSTM - 학습 방식
- 순전파 -> 오차 계산
- 역전파
    - 은닉상태와 셀 상태 두경로에 오차 정보가 전달됨
    - 은닉 상태에 영향을 준건 출력게이트
    - 셀상태에 영향을 준건 입력 게이트와 망각 게이트

#### LSTM의 한계
- 고정된 입출력 문제
    - 입력갯수만큼의 출력갯수만 뽑을 수 있음

- 이 문제를 해결한 방식이 바로 Seq2Seq
    - 입력받은 역할과 출력하는 역할을 나눠서 유연하게 대처할수 있도록함
