
# AI 에이전트

## LLM이란 무엇인가

- 1980년
    - 이전 토큰들을 기반으로 다음 토큰의 가능성을 예측
    - 새로운 텍스트 시퀀스를 생성

- 2017년 
    - 긴 문장에서 선택적으로 집중
    - 대규모 사전 학습에 용이

- 2018년
    - 마스킹 언어 모델링
    - 다음 토큰 예측

- 2022년
    - LLM 기반 모델로 텍스트와 시각, 음성 등의 모달리티를 결합하여 작업할 수 있는 모델
    - LLM이 단순한 응답 생성 모델을 넘어, 스스로 목표를 설정하고 계획, 실행하는 자율적 인공지능으로 진화

## 최고의 의사를 ChatGPT가 대신할 수 있을까?
- 범용 LLM
    - 모든 도메인에 대해서 일정 수준 이상의 응답이 가능한 대형 언어 모델
    - 가정의학과 전문의처럼, 넓은 지식 기반을 가지고 대부분의 문제에 1차 대응 가능

- 의료 특화 LLM
    - 의료 지식에 특화되어 있으며 진단, 처방, 환자 응대 등에 전문화된 모델
    - 내과, 외과 등의 전문의처럼, 의료 특정 도메인에 깊이 있는 지식을 갖춘 LLM

- 의료진 에이전트형 LLM
    - 같은 병이라도 의료진마다 진단, 치료 방식은 다름
    - 환자 상황, 병원 환경, 의료진의 임상 경험, 언어 습관까지



## AI Agent
### AI Agent의 개념

- AI Agent는 무엇일까?
    - AI를 사용해 목표를 추구하는 소프트웨어 시스템

- AI Agent의 주요 특성
    - 계획, 실행, 결정을 통해 인간 개입 없이 자율적 문제 해결

- AI Agent기술의 도전 과제는 무엇일까?
    - 보안과 같은 실무 응용 과제와 컨테스트

- 인공지능의 새로운 지평
    - 인공지능 분야는 빠르게 발전하고 있으며, AI 에이전트가 핵심적인 혁식 기술로 부상하면서 인간과 컴퓨터 상호 작용 및 자동화 영역을 새롭게 정의할 것으로 기대


- Perception AI
    - 특화된 분야에서 해석 및 분석
    - 현대 기계학습의 기반

- Generative AI
    - 콘텐츠 제작(텍스트, 이미지 등)

- Agentic AI
    - 능동적인 작업 수행
    - 자율형 문제해결 시스템

- Physical AI
    - 현실 세계에서 작동
    - AI 시스템이 물리적 실체를 얻음

- 에이전트란?
    - 에이전트: 다른사람 또는 단체를 대신해서 행동하는 개인 또는 단체
    - 에이전트는 특정 작업을 수행하고 결정을 내리며, 합의를 도출하는 것을 목표로함
    - AI 에이전트: AI를 사용하여 사용자를 대신해 목표를 추구하고 작업을 수행하는 소프트웨어 시스템

### AI 에이전트의 주요 특성
- 자율성
    - 인간의 개입 없이 계획하고, 실행하고, 결정하여, 문제를 자율적으로 해결할 수 있음

- 동작
    - 기능 호출을 통해 외부 도구를 사용하여 작업을 처음부터 끝까지 완료할 수 있습니다.

- 학습(적응)
    - 시간이 지남에 따라 피드백 및 출력을 학습하여 성능을 향상시키고 개인화함

- 추론(계획)
    - 목표를 여러개의 작은 작업들로 나누고, 실행하기 전에 합리적인 행동 계획을 구축할 수 있음

- 기억
    - 기억에 따라 상황을 처리하고 점점 더 정교한 도움을 제공할 수 있음

- 인식
    - 행동하기 전에 외부 데이터를 감지하여 환경을 인식하고 해석할 수 있음


## Multi-Agent System

- 대규모 언어 모델의 최신 성과
    - 창의적 글쓰기, 논리적 사고, 판단 능력
    - 인간 수준에 필적하는 성능

- 개별 LLM의 본질적 한계
    - 환각 현상: 부정확하거나 조작된 정보 생성
    - 자기회기적 성격: 천천히 생각하거나 신중한 추론을 할 수 없음
    - 스케일링 법칙: 모델 크기 증가에 따른 성능 향상 둔화

### 다중 에이전트 시스템의 필요성
- 집단 지성
    - 지능형 에이전트들이 팀을 이루어 협력하고 지식을 나누며, 함께 문제를 해결하는 능력에 초점을 맞춤
    - 인간사회는 일상 업무부터 과학 연구까지 팀워크와 역할 분담을 통해 공통 목표를 달성하는데 탁월

- 구성요소
    - 에이전트
    - 환경
    - 상호작용
    - 조직

### 에이전트 간의 협업 유형
- 협력과 경쟁의 조합
    - 협력과 경쟁의 전략적 조합
        - 에이전트들이 공동 목표 달성을 위해 특정 잡업에서는 협력하면서 동시에 다른 작업에서는 경쟁할 수 있도록 함
    - 전문가 혼합모델

- 규칙 기반 프로토콜
    - 사전에 정의된 규칙
        - 에이전트 간 상호작용은 미리 정의된 규칙에 의해 엄격히 통제
    - 인간의 협력 방식 모방

- 중앙집중형 구조
    - 참여자-서비스 제공자 구조
    - 중앙 에이전트

- 탈중앙화 구조
    - 에이전트에 대한 통제 및 의사결정 분산

## Memory & Tool
- 패러다임의 전환: 언어 모델에서 에이전트 시스템으로
    - AI는 전통적인 대규모 언어 모델에서 독립적 사고와 행동을 할 수 있는 자율적인 AI에이전트의 새로운 패러다임으로 발전할수 있다

- 기억/지식
    - 학습 데이터 범위를 넘어서는 광범위하고 변화하는 외부 정보를 활용 및 분석하는 능력
    - 핵심질문: 에이전트가 최신 정보를 어떻게 습듭하는가

- 메모리/도구
    - LLM 내장 매개 변수 메모리의 한계
        - 낡은 지식
        - 환각 현상
        - 사적 정보 접근 불가

- 검색 증강 생성
    - 핵심 아이디어 - LLM이 답젼을 생성하기전에 신뢰할 수 있는 외부소스
    - 장점: LLM이 자연스러운 표현력과 외부 지식의 정확성, 시의성, 검증 가능성을 결합하여 더욱 신뢰할 수 있고 근거가 확실한 답변을 생성
