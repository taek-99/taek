
# 머신러닝

## 학습 종류
- 지도학습
    - 정답지가 있음
    - 회귀
        - 연속적인 숫자 값을 예측
        - 선형회귀
    - 분류
        - 특징을 통해 분류
        - 로지스틱 회귀(이진분류)
            - 선형회귀 모델 + 시그모이드함수 + 이진 교차 엔트로피
        - 소프트맥스 회귀(다중 분류)
            - 선형회귀 + 소프트맥스(모든 클래스 확률 총합이 1) + 범주형 교차 엔트로피(정답 확률값에만 집중)

- 비지도 학습
    - 정답지가 없음
    - 군집화
        - 비슷한 데이터끼리 묶기
        - k-means: 데이터들이 중심점을 기준으로 그룹을 형성하도록 함
        - 계층적 군집: k값을 미리 정하지 않고, 거리를 가까운 순으로 묶는 방법
    - 차원축소
        - 데이터의 복잡성을 줄여서 핵심만 남김
        - 차원의 저주(데이터가 많으면과접학, 성능 문제, 학습시간)를 해결
        - PCA

- 강화학습
    - 상과 벌을 통해 학습


## 최소제곱법
- 에측 모델에서 비용을 최소화하는 가중치와 편향을 찾는 원리
- 정규방정식:
    - 복잡한 방정식을 한번에 계산
    
- 경사 하강법:
    - 최적의 파라미터를 점진적으로 찾아가는 방법
    - 이터레이션, 에포크
    - 학습률, 허용오차(학습 조기 종료 조건)
    - 배치 경사 하강법, 확률적 경사 하강법, 미니배치 경사하강법


## 데이터 EDA (중요)
- 모든 프로젝트의 첫 과정
- 분석의 방향성, 모델의 성능 향상, 새로운 인사이트 발견
- 데이터 로드, 정제 및 전처리, 개별 변수 분석, 변수 간 관계 분석, 분석 결과 정리

- 상관 관계
    - 두 변수가 함께 변화하는 관련성
    - 1과 1 사이의 값을 가짐
    - 양의 상관관계, 음의 상관관계, 상관관계 없음
    - 상관관계가 높다고 해서 인과관계가 있다는 것은 아님

- 데이터 시각화
    - matplotlib
        - 파이썬 시각화 라이브러리의 근간
    - seaborn
        - 데이터를 예쁘게 그림

- 데이터 시각화 그래프 종류
    - 히스토그램
    - 박스플롯
        - 사분위수: 25, 50, 75
        - 이상치: 25% - 1.5
    - 산점도
    - 히트맵
    - 페어플롯

## 모델학습
- 데이터 분리
    - 학습한 결과를 확인하기 위해서 데이터를 학습 데이터와 테스트 데이터로 분리해야함
    - train_test_split(훈련/ 테스트 데이터 분리), stratify=(클래스를 같은 비율로 분리)
    - 과적합
        - 훈련 데이터에만 너무 익숙해져서 잡음까지 외워버리는 현상
    - 과소적합
        - 모델이 너무 단순해서 훈련 데이터의 핵심 패턴조차 학습하지 못함

- 데이터 전처리
    - 스케일링
        - 표준화
            - 테스트 데이터의 표준화는 반드시 훈련 데이터의 평균/표준편차를 활용해야함

        - 정규화
            - 0~1값으로 축소
            - 이상치에 민감, 최소/최대값을 알아야함

## 모델 평가
- 선형회귀
    - MSE
- 분류
    - 정량적인 수치로 평가
    - 정확도
        - 맞은 예측개수/ 전체 예측개수
        - 불균형 데이터에서는 성능 평가 지표로 사용
    - 혼돈행렬
        - TP/ TN/ FP/ FN
    - 정밀도
        - 모델이 얼마나 정교한지를 나타냄
    - 재현율
        - 모델이 하나라도 놓치면 안될때 중요
    - 조화 평균

- 성능 검증
    - 평가한 데이터가 정말 신뢰성이 있는지 확인하기 위해서 데이터를 잘 나눴는지, 파라미터는 잘 설정했는지 확인하는 과정
    - 교차 검증
        - k-Fold

## 딥러닝
- 고전적인 머신러닝 학습 방법을 극복한 방법
- 인간의 뇌에서 영감을 받아서 만들어진 학습 방법론
    - 퍼셉트론
        - 인공 신경망의 기본적인 단위
- 신경망(얕은)
- 심층 신경망
    - 은닉층을 여러개로 깊게 쌓는 방식
    - 특징을 알려주지 않아도, 복잡한 패턴을 스스로 발견함

- MLP
    - 인공 신경망의 한종류로, 퍼셉트론을 여러 층으로 쌓은 모델
    - 학습 과정
        - 순전파
        - 손실 함수 계산
            - 회귀, 분류, 비지도
        - 역전파
        - 가중치 업데이트

- 학습 성능 향상
    - 활성화 함수(Relu)
        - 0보다 작으면 0, 0보다 크면 그대로 출력
    - 옵티마이저
        - 손실 함수의 값이 최소가 되는 최적의 가중치를 찾는 알고리즘
        - 경사 하강법이 대표적이며, 학습률이 높으면 오버슈팅, 학습률이 낮으면 지역 최저점에 빠짐
        - 가장 많이 쓰이는 방식이 Adam
    - 규제
        - 모델의 과적합을 막기 위해 제약을 거는 것
        - L1
            - 일부 가중치를 0으로 만들어 복잡도를 감소
        - L2
            - 가중치를 0에 가깝게 만듬
        - 드롭아웃
            - 학습 시 각 뉴런을 랜덤하게 일시적으로 학습시키지 않음

- Teacher Forcing
