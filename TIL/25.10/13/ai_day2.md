# 선형회귀 모델

## AI
- 인간의 학습, 추론, 지각 능력 등을 컴퓨터를 통해 구현하는 가장 포과절인 분야
- AI 구현하는 두가지 접근법
    - 규칙기반
        - 전문가의 지식과 규칙을 사람이 직접 컴퓨터에 코드로 입력하는 방식

    - 학습기반
        - 컴퓨터에게 데이터를 주고, 그 데이터 안에서 규칙을 스스로 배우게 하는 방식

## 머신러닝
- 컴퓨터에게 데이터를 주고, 그 데이터 안에서 규칙을 스스로 학습하게 하는 방식
- 학습 종류
    - 지도 학습
        - 정답지가 있는 데이터를 학습시키는 방법
    - 비지도 학습
        - 정답이 없는 데이터의 숨겨지느 구조나 규칙을 찾는 방법
    - 강화학습
        - 상과 벌을 통해서 최적의 행동방식을 학습하는 방법

- 지도학습
    - 정답이 있는 데이터를 학습시키는 방법
    - 지도학습 유형
        - 회귀
            - 연속적인 숫자 값을 예측하는 문제

        - 분류
            - 주어지 피처가 어떤 그룹에 속하는지 예측하는 문제

## 선형 회귀
- 예측을 하나의 직선으로 가장 간단하고 직관적인 방법
- 단순 선형회귀: 하나의 특성만 있을때

- 다중선형 회귀: 여러 특성이 있을 때

- 각각의 특성에 대한 최적의 가중치와 편향을 찾는 것이 목표

- 가설
    - 우리가 예측에 적용할 직선의 방정식(모델)을 지칭하는 용어

- 비용함수
    - 모델이 얼마나 좋은 모델인지 나타내는 점수(시간복잡도 등)
    - 비용함수 종류
        - 평균 제곱 오차
        - 평균 절대 오차
        - 교차 엔트로피

- 평균 제곱 오차
    - 모델의 예측값이 실제 정답과 얼마나 차이 나는지 측정하는 방법
    - 점수가 낮을수로 모델의 성능이 좋다는 의미
    - 계산 방법
        - 각 데이터들의 실제값과 예측의 차이를 구한다
        - 각 데이터들의 오차를 모두 제곱하야ㅕ 양수로 만들고 더하기
        - 제곱 총합을 데이터 개수로 나누어 평균을 구함
    - MSE점수를 0에 가장 가깝게 만드는 최적의 모델(가중치와 편향)을 찾는것

- 최소제곱법
    - 예측 모델에서 비용을 최소화하는 가중치와 편향을 찾는 원리
    - 최적의 w와 b를 찾는 방법
        - 정규 방정식
        - 경사 하강법
    
### 정규 방정식
- 복잡한 미분 방정식을 풀어서 한 번에 정답을 계산해내는 방법
- 만들어진 수학공식을 이용해 최적의 파라미터를 한 번에 계산
- 장점
    - 데이터의 특성이 적을때 빠르고 정확하게 해를 찾음
    - 추가설정이 필요없음
- 단점
    - 데이터가 많으면 속도가 매우 느려짐
    - 역행렬이 존재하지 않으면 계산할 수 없음

- 이런 역행렬이 존재하지 않으면 계산할 수 없는 문제는 특이값 분해로 해결

### 경사 하강법
- 최적의 파리미터를 점진적으로 찾아 나가는 방법
- 비용 함수의 기울기가 0이 되는 지점이 가장 비용이 낮은 지점
- 동작과정
    - 랜덤한 지점에서 시작해서 현재지점의 기울기를 구한다.
    - 해당 기울기만큼 움직인다.
    - 이동한 위치에서 다시 경사를 확인하고, 학습률만큼 이동한다.
    - 위 과정을 계속 반복하면서, 가장 낮은 지점에 도달
    
- 기울기만 큼 이동(학습률)할 때, 반대 방향으로 이동함
- 학습률 설정
    - 학습률이 너무 크면, 보폭이 너무 커서 반대편으로 올라갈 수 있음
    - 학습률이 너무 작으면, 오래 걸림

- 기울기
    - 전체 데이터가 만들어내는 평균적인 오차의 기울기

- 이터레이션
    - 데이터의 일부 혹은 전체를 보고 현재위치의 경사를 계산하고 한걸음 이동하는 과정

- 에포크
    - 전체 데이터를 모두 한번 훑어보면, 1 에포크

- 학습률
    - 한번에 얼마나 크게 움직일지를 결정하는 보폭

- 허용 오차
    - 학습 조기 종료 조건
    - 모델의 오차 감소량이 매우 작아지면, 학습해도 성능 향상이 없겠다고 판단하여 학습을 멈춤

- 배치 크기
    - 기울기를 구할때 전체 데이터 오차의 기울기를 한번에 구하지 않음
    - 작은 묶음로 나눠서 처리

- 기울기 누적 스텝
    - 실질적인 배치 크기를 늘리는 고급 기법

- 경사하강법의 종류
    - 배치 경사 하강법
        - 전체 데이터를 훑어보고, 기울기를 계산
        - 1에포크 = 1이터레이션
    - 확률적 경사하강법
        - 하나의 데이터만 보고 바로 기울기를 계산
        - 매우 빠르지만 불안
    - 미니배치 경사 하강법
        - 적당한 수의 배치만 보고 기울기를 계산

## 데이터 전처리
- 쓰레기를 넣으면 쓰레기가 나온다
- 컴퓨터는 유연하지 못함
    - 결측치
    - 문자열/ 범주형 데이터
    - 스케일링

- 결측치
    - 비어있는 값으로써, 데이터 전처리에 일반적으로 가장 먼저 마주하는 문제
    - 방법
        - 삭제
        - 대치

- 문자열/범주형 데이터
    - 컴퓨터가 알아 들을 수 있도록 문자 데이터를 숫자로 변환하는 과정
    - 레이블/ 원-핫/ 순서형/ 임베딩 등 다양한 방식으로 변환

- 스케일링
    - 각 특성의 단위를 맞춰서 모델이 공평하게 학습하도록 만드는 과정
    - 대표적으로 표준화와 정규화

    - 표준화
        - 단위가 다를 애들을 공평하게 맞춰줌
        - 데이터의 평균을 0, 표준 편차를 1로 변환
        - 특징
            - 이상치에 상대적으로 덜 민감하고, 정규분포를 따를 때 효과적
            - 모든 특성에 공평한 영향력을 부여

    - 정규화
        - 흩어져 있는 모든 데이터의 값을 0과 1사이의 범위로 변환
        - 데이터의 범위를 0~1로 명확하게 제한하고 싶은 경우에 활용
        - 특징
            - 데이터의 최소/최대값을 명확히 알면 유용함
            - 이상치에 민감
    
    - 일반적으로 표준화를 더 선호
