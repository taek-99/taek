# AI & 기계학습 기초 1
- AI와 ML은 무엇인가?

## AL, ML, DL의 정의

- AI
    - 주어진 환경/ 데이터를 인지하여 목표 달성을 하도록 예측, 행동 선택, 계획하는 시스템
    - 규칙기반 시스템
    - 휴리스틱 기반 알고리즘

- ML
    - AL 범주 내에서 데이터로부터 학습하여 목적을 달성하는 접근 방법론
    - 예: 언어모델, 이미지 분류 모델

- DL
    - ML 범주 내에서 신경망 함수를 사용한 학습 방법론


## 데이터와 학습의 이해
### 데이터 구성요소
- 데이터가 중요한 이유
    - 머신러닝은 규칙을 직접 코딩하지 않고, 데이터에서 규칙을 학습

- Feature
    - 모델이 예측에 사용하는 입력 정보

- Label
    - 모델이 예측하려는 정답

### 1D 피쳐 기반 학습
- 1D = 1차원
- Feature가 하나 일대 머신러닝이 학습하는 가장 단순한 형태

- 미지의 함수(f*)
    - 피처와 라벨의 실제 평균관계
    - 직접 관측할수는 없음
    - 오차가 포함된 데이터만 관측 가능

- 측정오차(e)
    - 데이터에는 주로 측정 오차가 섞여있음

### 모델과 가설 공간
- 학습
    - 입력과 출력의 관계를 찾는 과정
    - 평균 관계를 하나의 함수로 표현함

- 가설 공간
    - 관계를 표현할 수 있는 모든 후보 함수들의 모음

-  모델
    - 가설 공간 f에 속한 특정 함수 f

### 학습이란
- 주어진 데이터와 성능척도를 바탕으로 가설공간 f의 후보들 중 최적의 모델을 선택하는 과정

## 지도 학습
- 훈련 데이터가 아니라 처음 보는 테이터에서 예측 성능 향상

### 개념
- 데이터
    - 입력과 정답이 쌍으로 있는 데이터

- 목표
    - 새 입력이 들어오면 정답을 잘 맞추는 규칙을 학습

- 지도학습의 종류
    - 회귀: 예측값이 숫자
    - 분류: 예측값이 범주

### 회귀 문제
- 입력으로부터 숫자를 얼마나 정확히 에측할까
- 라벨 및 예측 모델의 출력


### 혼돈 행렬
- 예측과 실제 값 사이의 관계를 행렬 형태로 표현
- TP: 실제 양성, 예측도 음성
- TN: 실제 음성, 예측도 양성
- FP: 실제는 음성인데 양성이라 함(오탐)
- FN: 실제는 양성인데 음성이라 함(누락)


## 테스트 성능 평가
- 훈련 오류: 모델을 학습시킨 같은 데이터에 다시 적용해 계산한 오류
- 테스트 오류: 학습에 쓰지 않은 새 관측치에 대해 모델을 적용 했을 때의 평균 예측 오류
- 보통 훈련 오류는 테스트 오류와 다르며, 특히 훈련 오류는 테스트 오류를 과소평가하는 경우가 많음

## 검증셋(홀드아웃) 방법
- 가용 샘플들을 무작위로 훈련섹과 검증셋으로 분할
- 훈련셋으로 모델적합

- 검증 절차
    - 데이터 순서 무작위 셔플링 후 두 부분으로 분할.

### K-겹 교차 검증
- 테스트 오류 추정의 표준적 접근
- 추정치는 모델 선태고가 최종 모델의 테스트 오류 규모 파악에 활용

### 오버 피팅 vs 언더피팅
- 오버피팅: 모델이 지나치게 복잡
- 언더피팅: 모델이 지나치게 단순


## 비지도 학습
- 정의: 레이블 없이 데이터의 구조,패턴,집단을 찾아내는 학습
- 대표 과제: 군집화, 차원축소, 밀도 추정/ 이상치 탐지

### 비지도 vs 지도
- 지도학습: 입력+라벨로 예측 모델 학습
- 비지도학습: 입력만으로 구조 학습

- 비지도 학습 예
    - 클러스터링: 서로 비슷한 데이터끼리 묶어 동질 그룹 만들기

### 클러스터링
- 데이터 안에서 하위집단을 찾는 기법들의 총칭
- 목표: 집단 내부는 서로 유사, 집단 간은 상이하도록 데이터를 분할

- 두가지 대표 클러스터링 기법
    - k-평균: k를 미리 정해 분할
    - 계층적 군집: k를 사전에 고정하지 않음

### k-means 클러스터링
- 관측치 인덱스 집합을 C1,...,Ck라 하면: 각 관측치는 적어도 하나의 군집에 속함
- 모든 다른 클러스터에 대해 겹치지 않는다

- 핵심 아이디어
    - 좋은 군집화 = 클러스터 내부 변동이 작은 분할
    - 목표: 클러스터 내부 변동의 합이 최소가 되도록 분할을 찾는다.

- 알고리즘 단계별 진행
    - 무작위 클러스터 초기화
    - 중심계산
    - 클러스터 재배정 위에 2번 과정 반복

### 계층적 군집
- 계층적 군집은 k를 고정하지 않고 전체 구조를 덴드로그램으로 제공
- 이번 강의에서는 상향식을 다룸: 잎 -> 몸통으로 병합
