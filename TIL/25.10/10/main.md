# BST
- 특징
    - 자식 노드가 최대 2개이고, 데이터를 정렬된 형태로 저장하며 탐색, 저장, 삭제시 효율적인 자료구조이다.

- 장점
    - 데이터 삽입, 삭제 시 정렬된 상태를 유지한다.
    - 데이트럴 균형있게 분포하여 평균적으로 삽입, 삭제시 시간복잡도가 O(logn)이다.

- 단점
    - 트리가 한쪽으로 치우칠 경우 시간복잡도가 최대 O(n)으로 늘어난다.
    - 자식 노드를 2개씩 갖기 때문에 데이터의 크기가 커질경우 메모리 오버헤드가 발생할 수 있다.

- 주요연산
    - 탐색
        - 순서속성을 이용하여 루트 노드에서부터 왼쪽 또는 오른쪽 자식으로 이동시키며 키 값을 비교하여 주어진 키 값을 찾는 과정
    
    - 삽입
        - 새로운 노드를 삽입할때 BST의 특성을 유지하며 삽입할 위치를 찾기 위해 노드에서부터 적절한 위치까지 내려감

    - 삭제
        - 삭제할 노드의 자식 노드 수에 따라 3가지 경우로 나뉜다.
            - 자식 노드가 없을 경우(리프노드일 경우): 그냥 삭제 진행
            - 자식 노드가 하나일경우: 삭제할 노드의 자식노드를 부모 노드에 연결 후 삭제
            - 자식 노드가 2개일 경우: 중위 후속자 또는 중위
