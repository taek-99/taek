
## BST

- 특징
    - 자식 노드가 최대 2개를 가지며 데이터 삽입, 삭제시에도 정렬된 형태를 유지하며 효율적으로 수행한다.

- 구조
    - 기본적으로 이진트리의 특징을 가진다.
    - 왼쪽 자식 노드의 키값은 부모노드의 키값보다 작다
    - 오른쪽 자식 노드의 키값은 부모 노드의 키값보다 크다

- 장점
    - 데이터 삽입, 삭제 후에도 정렬된 상태를 유지한다. 
    - 데이터가 균형적으로 분포되어 탐색, 삽입, 삭제시 평균적으로 O(logN)의 빠른 연산속도를 가진다.

- 단점
    - 트리가 한쪽으로 치우칠 경우 시간 복잡도가 O(n)으로 늘어난다.
    - 두개의 자식노드를 갖기 때문에 데이터가 커질 경우 메모리오버헤드가 발생할수 있다.

- 주요연산
    - 탐색
        - 순서속성을 이용하여 루트 노드에서부터 시작하여 왼쪽 또는 오른쪽 자식으로 이동하면서 키값을 비교하여 주어진 키값을 찾는 과정

    - 삽입
        - 새로운 노드를 삽입할때 BST의 특징을 유지하며, 삽입할 위치를 찾기 위해 노드에서부터 적절한 위치까지 내려감

    - 삭제
        - 삭제할 노드의 자식 노드수에 따라 3가지 경우로 나뉜다.
            - 자식이 없는 리프노드일 경우: 그냥 삭제 진행
            - 자식 노느가 한개 있는 경우: 자식 노드를 삭제할 노드의 부모노드에 연결후 삭제
            - 자식 노드가 2개인 경우: 먼저 중위전임자 또는 중위후속자를 찾아서 연결후 중위 후속자의 값을 삭제할 노드에 복사 후 중위 후속자를 삭제한 후 중위 후속자의 상태에 따라 재귀적으로 반복한다.

## 힙
- 완전 이진트리의 노드 중에서 키값이 가장 크거나 가장 작은 노드를 찾기위해 만든 자료구조

- 주요연산
    - 삽입
        - 새로운 원소를 heap의 마지막 위치에 추가한다.
        - 시간복잡도
            - 최선: O(1)
            - 최악: O(logN)
    - 삭제
        - 루트 노드를 삭제후 힙의 마지막 요소를 루트 위치로 이동한다.
        - 시간복잡도
            - 최선: O(1)
            - 최악: O(logN)

## 이진검색
- 자료의 가운데에 있는 항목의 키값과 비교하여 다음검색의 위치를 결정하고 검색을 걔속 진행하는 방법
- 이진검색을 하기위해선 정렬된 상태여야 한다.
- 검색과정
    1. 자료의 중앙에 있는 원소를 고른다.
    2. 중앙 원소의 값과 찾고자 하는 목표값을 비교한다.
    3. 목표값이 더 작다면 왼쪽으로 이동, 목표값이 더 크다면 오른쪽으로 이동하여 새로 검색을 수행한다.
    4. 1~3을 반복하여 목표값을 찾는다.

## 병합 정렬
- 여러개의 정렬된 자료의 집합을 병합하여 한개의 정렬된 집합으로 만드는 방식
- 정렬과정
    1. 데이터를 같은 크기로 분할한다.(재귀를 통하여 더이상 나눌수 없을때까지 분할한다.)
    2. 나누어진 두 배열을 하나의 정렬된 배열로 병합한다.
    3. 위의 과정을 재귀적으로 반복하여 전체 배열이 병할될때까지 반복한다.
- 시간복잡도: O(nlogn)
- 안정성: O, 적응성: X, 제자리정렬: X

## 퀵정렬
- 주어진 리스트를 두개로 분할하여, 각각을 정렬하는 방식
- 정렬과정
    1. 리스트에서 피벗항목을 선정한다.
    2. 피벗보다 작은 요소는 왼쪽으로, 피벗보다 큰 요소는 오른쪽으로 이동시킨다.
    3. 2번 과정을 통해 최종위치에 놓인 피벗을 기준으로 왼쪽/오른쪽 부분 배열에 대해 각각 퀵 정렬을 재귀적으로 수행한다.
- 시간복잡도
    - 최선: O(nlogn)
    - 최악: O(n**2)
- 안정성: x, 적응성: O, 제자리정렬: O
