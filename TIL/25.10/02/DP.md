# DP

- 메모이제이션

    - 컴퓨터 프로그램을 실행할때 이전에 계산한 값을 메모리에 저장해서 매번 다시 계산하지 않도록 하여 전체적인 실행속도를 빠르게 구하는 기술

    - 동저계획법의 핵심이 되는 기술이다.


- 분할정복과 DP 비교

    - 분할정복

        - 연관 없는 부분 문제로 해결한다

        - 부분문제를 재귀절해으로 해결한다

    - DP

        - 부분 문제들이 연관이 없으면 적용할 수 없다.

        - 모든 부분 문제를 한번만 계산하고 결과를 저장하고 재사욘한ㄷ.
