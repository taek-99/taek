# 이진탐색 트리

## BST
- 데이터를 효율적으로 관리하기 위한 자료구조 

- 특징
    - 각 자식 노드가 최대 2개이다.
    - 데이터를 정렬된 형태로 삽입, 삭제, 탐색 할때 효율적이다

- 구조
    - 이진 트리의 특성을 가지지만 추가로 다음과 같은 속성을 가짐
        - 왼쪽자식 노드의 키값이 부모노드의 키값보다 작다
        - 오른쪽 자식 노드의 키값이 부모노드의 키값보다 크다

- 장점
    - 데이터 탐색, 삽입, 삭제시 효율적으로 관리 가능하여 O(logN)의 시간 복잡도를 갖는다.
    - 데이터가 정렬된 상태를 유지하며 삽입, 삭제 후에도 정렬된 상태를 유지한다.

- 단점
    - 트리가가 한쪽으로 치우쳐질 경우 최악으로 O(n)의 시작 복잡도를 갖는다
    - 각 노드는 2개의 자식을 가지므로 데이터 집합이 커질 경우 메모리 오버헤드가 발생한다.

- 주요연산
    - 탐색: 순서속성을 이용하여 루트노드에서부터 시작해 왼쪽 혹은 오른쪽자식으로 이동하여 키값을 비교하여 주어진 키값을 찾는 과정

    - 삽입: 새로운 노드를 삽입할때 BST의 특징을 유지하며, 삽입할 위치를 위해 노드에서부터 적절한 위치까지 내려감

    - 삭제: 삭제하려는 노드의 위치와 자식 노드의 유무에 따라 3가지 경우로 나뉨
        - 삭제하려는 노드가 리프노드일 경우 -> 그냥 삭제 진행
        - 삭제하려는 노드의 자식 노드가 1개일 경우 -> 삭제할 노드의 자식 노드를 부모 노드에 연결
        - 삭제하려는 노드의 자식 노드가 2개일 경우 -> 중위 후속자 또는 중위 전임자 찾아서 연걸후 중위 후속자의 값을 삭제할 노드에 복사후 중위 후속자를 삭제하고 중위 후속자의 상태에 따라 재귀적으로 반복


## 힙
- 완전 이진트리에 있는 노드중에서 키값이 가장 크거나 작은 노드를 찾기위해 만든 자료구조

- 주요연산
    - 삽입
        - 새로운 원소를 heap의 마지막 위치에 추가한다.
        - 시간복잡도
            - 최선: O(1)
            - 최악: O(logN)
   
    - 삭제
        - 루트 노드를 제거하고, 힙의 마지막 요소르 루트 위치로 이동한다.
        - 시간복잡도
            - 최선: O(1)
            - 최악: O(logN)


# 분할정복
- 복잡한 문제를 더 작은 하위 문제들로 나누어 해결하는 알고리즘

- 설계전략
    - 분할: 해결할 문제를 여러개의 작은 문제로 나눈다.
    - 정복: 나눈 문제를 각각 해결한다.
    - 통합: 해결된 해답을 모은다.


## 이진검색
- 자료의 가운데에 있는 항목의 키값과 비교하여 다음 검색의 위치를 결정하고 검색을 계속 진행하는 방법
- 이진검색을 하기위해선 정렬된 상태여야 한다.
- 검색 과정
    1. 자료의 중앙에 있는 원소를 고른다.
    2. 중앙 원소의 값과 찾고자 하는 목표값을 비교한다.
    3. 목표값이 작으면 자료의 왼쪽 절반에서 새로 검색을 수행하고, 목표값이 크다면 자료의 오른쪽 절반에서 새로 검색을 수행함.
    4. 1~3번을 반복하여 목표값을 찾음

## 병합정렬
- 여러개의 정렬된 자료의 집합을 병합하여 한 개의 정렬된 집합으로 만드는 방식
- 정렬과정
    1. 자료를 동일한 크기의 두 배열로 분할한다. -> 재귀를 통하여 더이상 나눌수 없을때까지 분할한다.
    2. 나눠진 두 부분 배열을 하나의 정렬된 배열로 병한한다.
    3. 위의 과정을 재귀적으로 적용하여 전체 배열이 정렬될때까지 반복한다.
- 시간복잡도: O(logN)
- 안정성: O
- 적응성: X
- 제자리 정렬:X 
- 큰 데이터 셋을 정렬할떄 유용하고 안정적이고, 예측 가능한 성능

## 퀵정렬
- 주어진 리스트를 두개로 분할하고, 각각 정렬한다.
- 퀵 정렬을 분할할때, 피벗을 중심으로 작은것은 왼편, 큰것은 오른편에 위치한다.
- 정렬과정
    1. 리스트에서 하나의 피벗을 선택한다.
    2. 피벗보다 작은 요소들은 왼쪽으로, 큰 요소들은 오른쪽으로 이동시킨다.
    3. 2번과정을 통해 최종위치에 놓인 피벗을 기준으로 왼쪽/오른쪽부분 배열에 대해 각각 퀵 정렬을 재귀적으로 수행한다.
    4. 부분 배열의 크가기 1 이하가 되면 재귀를 종료한다.
- 최악 시간복잡도: O(n**2)
- 최선 시간복잡도: O(nogn)
- 안정성: x
- 적응성: o
- 제자리 정렬: o 

# DP

## 매모이제이션
- 컴퓨터 프로그램을 실행 할때 이전에 계산한 값을 메모리에 저장해서 매번 다시 계산하지 않도록 하여 전체적인 실행 속도를 빠르게 하는 기술
- 동적계획법의 핵심이 된다.
- 탑 다운 접근 방식이다.
- 추가적인 메모리가 필요하다.


## DP란
- 동적계획 알고리즘은 그리디 알고리즘과 같이 최적화 문제를 해결하는 알고리즘이다.
- 다음의 조건이 필요하다.
    - 중복 부분문제 구조
    - 최적 부분문제 구조

- 중복 부분문제 구조
    - 큰 문제를 해결하기 위해 작은 문제들을 먼저 해결하고 작은 문제들의 최적화를 이용하여 순환적으로 큰 문제를 해결
    - 점화식 사용
    - 순환적인 성질때문에 이전에 계산되었던 작은 문제의 해가 다른 어딘가에서 필요하게 되는데 이를 위해 DP에서는 이미 해결된 작은 문제들의 해들을 어떤 저장공간에 저장하게 된다.

- 최적 부분문제 구조
    - 주어진 문제가 최적화의 원칙을 만족해야만 동저계획법을 효율적으로 적용할 수 있다.
    - 최적화의 원칙이란 어떤 문제에 대한 해가 최적일때 그 해를 구성하는 작은 문제들 역시 최적이어야 한다.
 

- 분할 정복과 동적 계획법의 비교
    - 분할 정복
        - 문제를 해결하기 위해 부분 문제로 분할한다.
        - 부분 문제를 재귀적으로 해결한다.
    - DP
        - 부분 문제들이 연관이 없으면 적용할 수 없다.
        - 모든 부분 문제를 한번만 계산하고 결과를 저장하고 재사용한다.
