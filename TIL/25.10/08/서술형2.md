1. BST
    - 이진트리 구조를 가지며 자식 노드로 2개를 가지고 데이터 삽입, 삭제, 탐색시 효율적이다.

    - 장점
        - 데이터 삽입, 삭제시에도 정렬된 상태를 유지한다.
        - 시간 복자도 O(logN)이다.
        - 동적으로 크기를 조정할 수 있어 고정된 배열에 비해 유연성이 높다.

    - 단점
        - 트리가 한쪽으로 치우칠 경우 시간 복잡도가 O(n)으로 늘어난다.
        - 각 노드의 자식 노드가 2개이기때문에 데이터가 커질경우 메모리 오버헤드가 발생 할 수 있다.

    - 주요연산
        - 탐색
            - 순서 속성을 이용하여 루트노드에서부터 값이 작을경우 왼쪽 값이 클경우 오른쪽으로 이동하면서 키값을 비교하며 목표값을 찾는 과정

        - 삽입
            - 새로운 노드를 삽입해 BST특징을 유지하며, 삽입할 위치를 찾기 위해 노드에서부터 적절한 위치까지 내려감

        - 삭제
            - 삭제할 노드의 자식 노드의 수에 따라 행동이 달라짐
                - 리프노드: 그냥 삭제 진행
                - 자식 노드가 한개일 경우: 자식 노드를 부모노드에 연결후 삭제
                - 자식 노드가 2개일 경우: 중위 전임자와 중위 후속자를 찾아 값을 비교하여 부모 노드와 연결 후 중위 후속자의 값을 삭제할 노드에 복사 후 중위 후속자를 삭제하고 중위 후속자의 상태에 따라 재귀적으로 반복

2. 힙
- 완전 이진트리에서 키값이 가장크거나 가장 작은 노드를 찾기위해 만든 자료구조

- 주요연산
    - 삽입
        - 새로운 원소를 heap의 마지막 위치에 추가한다
        - 시간복잡도 
            - 최선: O(1)
            - 최악: O(logn)
    - 삭제
        - 루트 노드를 제거하고 힙의 마지막 요소를 루트 노드 위치로 이동한다.
        - 시간복잡도
            - 최선: O(1)
            - 최악: O(logn)

3. 분할정복
- 복잡한 문제를 작은 문제로 나누어 해결하는 알고리즘
- 설계전략
    - 분할: 해결할 문제를 여러개의 작은 문제로 나눈다.
    - 정복: 나눈 문제를 각각 해결한다.
    - 통합: 해결된 해답을 모은다

4. 이진검색
- 자료의 가운데에 있는 항목의 키값과 목표값을 비교하여 다음 검색 위치를 결정하고 검색을 계속 진행하는 방법
- 이진검색을 하기위해선 자료가 정렬된 상태여야 한다.
- 검색과정
    1. 자료의 중앙에 있는 원소를 고른다.
    2. 중앙 원소의 값과 찾고자 하는 목표값을 비교한다.
    3. 목표값이 중앙 원소의 값보다 작으면 자료의 왼쪽반, 크다면 오른쪽 반에 대해서 새로 검색을 수행한다.
    4. 1~3을 반복하여 목표값을 찾는다.

5. 병합 정렬
- 여러개의 정렬된 자료의 집합을 병합하여 한개의 정렬죈 집합으로 만드는 방식
- 정렬과정
    1. 주어진 배여를 같은 크기의 두배열로 나눈다 (이 과정을 재귀적으로 더 나눌수 없을때까지 나눈다.)
    2. 나눠진 두 배열을 하나의 정렬된 배열로 병합한다.
    3. 위의 과정을 재귀적으로 적용하여 전체 배열이 정렬될때까지 반복한다.
- 시간복잡도: O(nlogn)
- 안정성: O, 적응성: X, 제자리정렬:X

6. 퀵정렬
- 주어진 리스트를 두개로 분할하고, 각각을 정렬한다.
- 퀵 정렬이 분할할때, 기준아이템을 중심으로 이보다 작으면 왼쪽으로, 크면 오른쪽에 위치하게 한다.
- 정렬과정
    1. 리스트에서 피벗요소를 정한다.
    2. 피벗보다 작은 요소를 왼쪽으로, 큰 요소를 오른쪽으로 이동시킨다.
    3. 2번 과정을 통해 최종위치에 놓인 피벗을 기준으로 왼쪽/ 오른쪽 부분배열에 대해 각각 퀵 정렬을 재귀적으로 수행한다.
    4. 부분 배열의 크기가 1 이하가 되면 재귀를 종료한다.
- 최악 시간 복잡도: O(n**2)
- 최선 시간 복잡도: O(nlogn)
- 안정성 x, 적응성: O, 제자리정렬: O

7. 메모제이션
- 컴퓨터 프로그램이 실행할때 이전에 계산한 값을 메모리에 저장해서 매번 다시 계산하지 않도록 하여 전체적인 실행속도를 빠르게 하는 기술
- 탑다운 접근방식
- 추가적인 메모리 공간이 필요하다


8. DP란
- 동적계획 알고리즘은 그리디 알고리즘과 같이 최적화 문제를 해결하는 알고리즘이다.
- 다음의 조건이 필요하다.
    - 중복 부분문제 구조
    - 최적 부분문제 구조

- 중복 부분문제 구조
    - 큰 문제를 해결하기 위해 작은 문제들로 나누어 최적화를 이용하여 순환적으로 큰 문제를 해결한다.
    - 점화식을 사용한다.
    - 순환적인 성질 떄문에 이전에 계산되었던 작은 문제의 해가 다른 어딘가에 필요하게 되는데 이를 위해 DP에서는 이미 해결된 작은 문제들의 해들을 어떤 저장공간에 저장하게 된다.

- 최적 부분문제 구조
    - 주어진 문제가 최적화의 원칙을 만족해야만 동적계획법을 효율적으로 적용할 수 잇다.
    - 최적화의 원칙이란 어떤 문제에 대한 해가 최적일때 그 해를 구성하는 작은 문제들의 해 역시 최적이여야 한다.

- 분할 정복과 DP 비교
    - 분할정복
        - 연관없는 부분 문제로 분할한다.
        - 부분 문제를 재귀로 해결한다
    - DP
        - 부분문제들이 연관이 있어야 한다.
        - 모든 부분 문제를 한번만 계산하고 결과를 저장하고 재사용한다.
