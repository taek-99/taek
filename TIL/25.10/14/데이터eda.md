# 데이터EDA

## 탐색적 데이터 분석
- 데이터를 본격적으로 분석하기 전에 여러 각도에서 관찰하고 이해하는 과정
- 데이터에 대해 깊은 이해를 얻을 수 있으며, 모든 프로젝트의 첫과정
- 중요성
    - 분석의 방향성 제시
    - 모델의 성능 향상
    - 새로운 인사이트 분석

### 데이터 분석 진행순서
- 데이터를 불러오고, 기본정보를 확인
- 데이터 정제 및 전처리
- 개별 변수 분석
- 변수 간 관계 분석
- 분석 결과 정리

- 상관관계
    - 두 변수가 함께 변화화는 관련성을 의미
    - 하나의 변수가 증가/감소 할때, 다른 변수가 어떤 일정한 관련성을 띄며 함께 변화하는지 나타내는 지표

- 특정 수치형 변수 하나의 데이터 분포를 파악하기 위해서 사용
- 장점
    - 직관적으로 분포를 파악할 수 있음
    - 이상치 탐지가 수월

- 단점
    - 구간 설정에 민감

### 단변수 분석 - 박스 플롯
- 수치형 데이터의 분포와 이상치를 한눈에 파악하기 위해 사용되는 그랲
- 데이터의 산분위수를 이용하여 전체 데이터가 어떻게 퍼져있는지를 간결하게 요약

### 이상치 
- 이상치는 다른 데이터와 비교했을 때 값이 너무 크거나 작아서 눈에 띄는 데이터를 말합니다. 예를 들어 대부분 사람들이 150~190cm 사이의 키를 가지고 있는데, 250cm가 나온다면 이는 이상치일 가능성이 큽니다. 이상치는 데이터 입력 실수, 측정 오류, 혹은 정말 드문 특별한 경우 때문에 발생할 수 있습니다. 분석 전에 이런 값을 확인하고, 잘못된 값이면 제거하거나 경계값으로 바꾸고, 의미가 있다면 그대로 두는 것이 좋습니다.

IQR(사분위 범위)은 이상치를 찾는 대표적인 방법 중 하나입니다. 먼저 데이터를 작은 값부터 큰 값까지 순서대로 정렬하고, 아래쪽 25% 지점(Q1)과 위쪽 25% 지점(Q3)을 찾습니다. IQR은 Q3에서 Q1을 뺀 값으로, 데이터의 중간 50% 범위를 의미합니다. 이상치는 보통 Q1보다 1.5 × IQR만큼 작거나, Q3보다 1.5 × IQR만큼 큰 값으로 정의합니다. 이 방법은 평균과 표준편차를 쓰는 방법보다 극단값에 덜 민감하고, 데이터가 정규분포를 따르지 않아도 사용할 수 있다는 장점이 있습니다.

## 모델 학습

### EDA를 통해 데이터 분석이 끝났으니, 모델에 데이터를 학습시켜 보자
- 과적합
    - 주어진 모든 데이터를 학습시키면 과하게 최적화되어 훈련에서는 좋은 성능을 보이지만 실제 테스트에서는 성능이 나빠지는 현상

### 과적합
- 머신러닝 모델이 훈련데이터에만 너무 익숙해져서, 데이터의 중요한 패턴을 넘어 사소한 잡음까지 전부 외워버리는 현상


### 과소적합
- 모델이 너무 단순해서 훈련 데이터의 핵심적인 패턴조차 제대로 학습하지 못한 상태


### 데이터 분리
- 주어진 데이터를 훈련데이터와 테스트 데이터로 분리
- 훈련 데이터: 모델을 학습시키는 용도
- 테스트 데이터: 모델이 얼마나 새로운 데이터를 잘 예측하는지 일반화 성능을 최종 평가하는 용도

### 스케일링 - 표준화
- 테스트 데이터의 표준화는 반드시 훈련데이터의 평균/표준편차를 활용해야함

## 성능평가

### 성능 평가
- 선형회귀 모델은 MSE를 활용해서 모델을 평가
- 평가지표
    - 정확도
    - 정밀도
    - 재현율
    - 조화 평균

### 분류 모델 성능 평가 - 정확도
- 맞은예측개수/ 전체예측개수
- 가장 이해하기 쉽고 직관적인 성능 평가 지표
- 정확도는 안심할 수 없음

### 분류 모델 성능 평가 - 혼돈행렬
- 분류 모델의 성능을 평가할때 사용하는 가장 기본적이면서도 강력한 도구
- Positicve: True
- Negative: 그외 대상
- 구성요소
    - TP
        - 모델이 Positicve으로 예측한것
    - TN
        - 모델이 Negative으로 예측한것
    - FP
        - 실제로 Neagtive인거지만 Positive로 잘 못 예측한것
        - 모델의 섣부른 판단
    - FN
        - 실제로 Positive인 것을 모델이 Negative로 잘 못 예측한것
        - 모델이 놓침

### 분류 모델 성능 평가 - 정밀도
- 모델이 positive로 예측한것중에 positive가 맞은것


### 분류모델 성능평가 - 재현율
- 실제 포지티브중에 모델이 포지티브라고 맞춘 비율

### 교차 검증

## 비지도 학습
- 정답이 없는 데이터의 구조나 규칙을 찾는 방법
- 비지도 학습 유형
    - 군집화
    - 차원축소

### 군집화
- 정답이 없는 데이터들을 유사한 특징을 가진것끼리 하나의 그룹으로 묶는 작업
- 정답이 없어도 되기 때문에 레이블링 작업이 불필요
- 군집화 알고리즘
    - K평균
    - 계층적군집

### K-means
- 데이터들이 가장 까가운 중심점을 기준으로 뭉치도록 그룹을 형성하도록 하는 알고리즘
- 동작방식
    - k개의 중심점을 데이터 공간에 랜덤 배치
    - 모든 데이터는 자신과 가장 가까운 중심점과 그룹을 형성
    - 각 그룹의 평균을 계산하고, 그 지점을 다시 중심점으로 설정
    - 새로 생성된 중심점을 기준으로 2~3번 과정을 더 이상 변화가 없을때까지 반복
- 이상치에 민감하고, 초기 중심점의 위치에 따라 결과가 달라질수 잇음
- 군집의 개수를 직접 지정해야함

### 계층적 군집
- k-means와 달리 k값을 미리 정하지 않아도 되는 군집
- 데이터 간의 거리를 바탕으로 가까운것부터 순서대로 묶어가면서 나무 형태의 구조를 만들어가는 방식

## 차원축소
- 차원의 저주
    - 데이터의 차원이 증가할수록, 데이터를 분석하는데 필요한 공간의 부피가 기하급수적으로 커져 발생하는 문제
    - 문제점
        - 불필요한 노이즈가 많아져 모델의 예측 성능이 떨어짐
        - 과접합 늘어남
        - 시간 오래 걸림
        - 3차원 이상은 시각화 어려움
- 특성 선택
    - 여러 특징 중에서 가장 중요하다고 생각되는 몇개의 특징만 골라내는 방식
- 특성 추출
    - 기존 특징들을 새로운 축으로 투영하여, 더 적은 수의 새로운 특징으로 압축하는 방식
    - PCA

### PCA
- 데이터가 가장 넓게 퍼져 있는 방향으로 새로운 축을 찾는 기술
- 새로운 축이 바로 데이터의 정보를 가장 잘 설명하는 제 1주성분
