# MLP

## 딥러닝

- 인간의 뇌에서 영감을 받은 인공신경망을 사용하여 복잡한 패턴을 학습하는 머신러닝 학습 방법론
- 핵심 아이디어
    - 뇌의 신경망 구조와 동작 방식을 컴퓨터로 모방
    - 뇌가 수십억개의 신경세포들이 서로 신호를 주고 받으며 학습하고 판단
- 인공신경망
    - 컴퓨터 안에 인공뉴런을 만들고, 이들을 연결하여 네트워크 구축


## 퍼셉트론
- 여러 정보를 받아서 최정족으로 참 또는 거짓과 같은 결정을 내리는 간단한 결정모델
- 인공 신경망의 가장 기본적인 단위로, 사람의 뇌를 구성하는 뉴런의 작동 원리를 모방한 알고리즘
- 구성요소
    - 입력
    - 가중치
    - 가중합
        - 모든 입력에 각각의 가중치를 곱한 뒤, 모두 더한 값
    - 활성화 함수
        - 입렫된 신호를 받아 그 신호를 처리하여 출력신호를 결정하는 함수

- 데이터 사이에 직선 하라는 그어서 두 그룹을 나누는것과 같음
- 퍼셉트론은 선형 분리 가능한 문제를 잘 해결함
- XOR문제를 해결할 수 없는 치명적인 문제를 가지고 있음

## 뉴럴 네트워크

### 얕은 신경망
- 초기 인공신경망의 형태
- 얕은 신경망
    - 입력/은닉/출력 3가지 계층으로 이루어짐
    - 은닉층이 딱 하나만 있는 구조
- 만능 근사 이론
    - 이론적으로 은닉층에 뉴런이 충분히 많다면 단 하나의 은닉층만으로도 세상의 거의 모든 연속적인 함수를 흉내 낼 수 있음

### 심층 신경망
- 신경망을 옆으로가 아닌 깊게 쌓는 방식
- 여러개의 은닉층을 가진 인공 신경망
- 더 복잡하고 고차원적인 특징 학습
- 사람이 특징을 알려주지 않아도, 복잡한 패턴을 스스로 발견

## MLP

### 다중 퍼셉트론
- 인공 신경망의 한 종류로, 퍼셉트론을 여러 층으로 쌓은 모델
- MLP의 학습과정
    - 순전파
    - 손실 함수 계산
    - 역전파 및 가중치 업데이트
    - 1~3번 반복 후 종료

#### 순전파
- 데이터가 입력층에서 시작해서 여러 은닉층을 거쳐 출력층까지, 앞에서 뒤로 흘러가면서 계산되는 과정
- 순전파 과정
    - 초기에 각 뉴런들은 무작위 가중치를 갖음
    - 데이터가 연결된 입력츠응로 들어감
    - 각 뉴런은 입력값과 무작위로 초기화된 가중치를 이용해 계산, 활성화 함수를 통과시켜 결과를 다음층으로 전달
    - 마지막 출력층까지 반복되어 최종 예측값을 출력

#### MLP 학습과정
- 순전파 과정에서 나온 결과를 실제 정답과 비교해서 손실/오차를 구함
- 구하는 방법
    - 회귀
    - 분류
    - 비지도

#### MLP 학습과정 - 역전파
- 손실 값을 가지고 출력층에서 거꾸로 계산하면서 가중치를 업데이트 하는 과정
- 역전파과정
    - 발생한 오차를 가지고, 이전층으로 거꾸로 추적하면서 각 가중치가 오차에 준 영향을 구함
    - 계산된 영향력을 바탕으로 오차를 줄이는 방향으로 각 가중치를 조금씩 업데이트
    - 첫은닉층까지 반복 후 다시 순전파 반복

#### 역전파 진행 과정
- 예측갑과 정답 차이에서 하나의 "최종오차"발생

- 최종오차가 뒤로 전파되면서 각 뉴련은 최종오차에 대한 각기 다른 책임 신호를 전달 받는다.
    - 책임 신호는 뉴런의 출력값이 최종오차에 얼마나 영향을 미쳤는지를 나타냄
    - 수학적으로 최종오차를 각뉴런의 출력으로 편미분

- 뉴런 내부의 각 (가중치*입력데이터)는 책임신호에 각기 다른 영향을 미쳤고, 이 영향력에 맞춰서 가중치를 수정해야 한다.

- (가중치*입력데이터)의 영향력에서 실질적으로 책임신호에 영향을 주는 부분은 입력데이터(X)이다.

- 그렇기에 기존에 있던 가중치는 신경쓰지 말고, 입력데이터와 책임 신호를 곱해서 최종책임신호를 계산 후 학습률과 곱해서 각 가중치 값을 업데이트 한다.

### MLP 성능 향상
- 대표적인 성능 향상 기술

    - 옵티마이저
    - 과적합 예방 규제

#### Adam
- 현재 딥러닝 모델의 80%이상이 사용하는 사실상 표준 옵티마이저
- 이름처럼 적응적으로 학습률을 조절하는것이 핵심
- Adam의 아이디어
    - 관성 도입
        - 현재 위치의 기울기만 보고 움직이는 경사하강법과 다르게 이전가지 이동해온 속도와 방향을 기억

    - 적응적 학습률 도입
        - 가중치마다 고유한 학습률을 부여하여, 최적의 학습속도를 유지하여 효율적으로 낮은 손실지점에 도달
        - 많이 움직였던 만큼 가중치에 대해서 학습률을 작게 만들어서,
