## FORM

- 지금까지 사용자로부터 데이터를 제출 받기 위해 활용한 방법. 그러나 비정상적 혹은 악의적인 요청을 필터링 할 수 없음

- 유효한 데이터인지 검사필요

- 유효성 검사

    - 수집한 데이터가 정확하고 유효한지 확인하는 과정

    - 유효성 검사를 구현하기 위해서는 입력값, 형식, 중복, 범위, 보안 등 많은 것들을 고려해야함

- Form class

    - model이랑 비슷한 방식

- widgets

    - 단순히 input 요소의 속성 및 출력된느 부분을 변경하는 것
