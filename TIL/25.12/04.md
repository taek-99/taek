# Router

## views
- RouterView 위치에 렌더링 할 컴포넌트를 배치
- 기존 components 폴더와 기능적으로 다른것은 없으며 단순 분류의 의미로 구성된

## 라우팅 기본 동작 순서
- index.js에 라우터 관련 설정 작성(주소, 이름, 컴포넌트)
- RouterLink에 index에 정의한 주소 값 자것ㅇ
- RouterLink 클릭 시 경로와 일치하는 컴포넌트가 RouterView에서 렌더링

## 다이나믹 라우트 매칭
- URL의 일부를 변수로 사용하여 경로를 동적으로 매칭

- path의 맨 긑에 : 붙인후 입력
- params: {'id' : userID } 로 동적 ID 전송

## Nested Routes
- 중첩된 라우팅
- children을 활용하여 중첨된 라우터에 컴포넌트 등록
 -배열 형태로 여러개 추가 가능

 ## programmatic navigation
 - 라우트링크를 클릭하는 대신, 자바스크립트 코드를 사용해 페이지를 이동시키는것
 - 프로그래밍으로 URL 이동하기
 - router의 메서드
    - router.push
    - router.replace
