# Router

## views
- RouterView 위치에 렌더링 할 컴포넌트를 배치
- 기존 components 폴더와 기능적으로 다른것은 없으며 단순 분류의 의미로 구성된

## 라우팅 기본 동작 순서
- index.js에 라우터 관련 설정 작성(주소, 이름, 컴포넌트)
- RouterLink에 index에 정의한 주소 값 자것ㅇ
- RouterLink 클릭 시 경로와 일치하는 컴포넌트가 RouterView에서 렌더링

## 다이나믹 라우트 매칭
- URL의 일부를 변수로 사용하여 경로를 동적으로 매칭

- path의 맨 긑에 : 붙인후 입력
- params: {'id' : userID } 로 동적 ID 전송

## Nested Routes
- 중첩된 라우팅
- children을 활용하여 중첨된 라우터에 컴포넌트 등록
 -배열 형태로 여러개 추가 가능

 ## programmatic navigation
 - 라우트링크를 클릭하는 대신, 자바스크립트 코드를 사용해 페이지를 이동시키는것
 - 프로그래밍으로 URL 이동하기
 - router의 메서드
    - router.push
    - router.replace


## Navigation Guard
- Globally(전역 가드)
   - 애플리케이션 전역에서 모든 라우트 전환에 적용되는 가드

- Pre-route(라우터 가드)
   - 특정 라우트에만 적용되는 가드

- In-component(컴포넌트 가드)
   - 컴포넌트 내에서만 적용되는 가드


### Globally
- beforeEach
   - 다른 URL로 이동하기 직전에 실행되는 함수
   - to: 이동 할 URL정보가 담긴 Route 객체
   - from: 현재 URL 정보가 담긴 Route 객체
   - 선택적으로 다음 값중 하나를 반환
      - false
      - Route Location

- beforeResolve()
   - 비포이치와 모든 컴포넌트 단위 가드가 실행된 후, 내비게이션이 확정되기 직전에 호출
   
- afterEach()
   - 내비게이션이 완전히 확정된 후, 즉 URL이 변경되고 화면 렌더링이 끝난 뒤에 호출
   - 후처리 작업에 적합

## Per-route Guard
- index.js의 각 라우트에 활용
- beforeEnter()
   - 다른 URL에서 탐색해올때만 실행됨

## In-component Guard
- 각 script의 내부
- onBeforeRouteLeave()
   - 현재 라우트에서 다른 라우트로 이동하기 전에 실행
- onBeforeRouteUpdate()
   - 이미 렌더링 된 컴포넌트가 같은 라우트 내에서 업데이트 되기 전에 실행
