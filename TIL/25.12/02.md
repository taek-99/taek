# SFC

## Component
- 재사용 가능한 코드 블록

## SFC
- 컴포넌트의 템플릿, 로직 및 스타일을 하나의 파일로 묶어낸 특수한 파일 형식

### template
- 각 vue파일에 하나만 만들수 있음

### script 
- setup이 붙어있는 블록은 각 vue파일에 하나만 만들 수 있음
- setup을 붙여야 각 컴포넌트의 각 인스턴스에 대해 실행함

### style
- scoped가 지정되면 css는 현재 컴포넌트에만 적용됨

## Vite
- 프론트엔드 개발 도구로써 빠른 개발 환경을 위한 빌드 도구와 개발 서버를 제공
- Build
    - 프로젝트의 소스 코드를 최적화하고 번들링하여 배포할 수 있는 형식으로 변환하는 과정
    - 번들링: 여러개로 흩어진 코드 파일을, 하나로 합쳐주는 작업

## npm
- Node.js의 기본 패키지 관리자
- npm은 개발자들이 만든 js 패키지를 모아놓은 거대한 저장소이자,, 그 패키지들을 쉽게 설치하고 관리할 수 있게 해주는 명령어 도구
- 프로젝트에 사용된 모든 패키지들의 목록과 버전을 package.json파일에 기록하여 다른사람과 협업하거나 다른 환경에서 작업할때도 동일한 개발 환경을 쉽게 구축할 수 있도록 도와줌

- nodejs
    - chrome의 v8 js엔진을 기반으로 하는 Server-Side 실행 환경
    - 브라우저 안에서만 동작할 수 있었던 js 브라우저가 아닌 서버측에서도 실행할 수 있게 함

## 모듈
- 프로그램을 구성하는 독립적인 코드 블록
- 모듈의 한계
    - 애플리케이션 점점 더 발전함에 따라 처리해야 하는 JavaScript 모듈의 개수도 극적으로 증가
    - 이러한 상황헤서 성능 병목 현상이 발생하고 모듈간의 의존성이 깊어짐
    - 모듈간의 복잡성을 해소하는 도구가 Bundler

## Bundler
- 여러 모듈과 파일을 하나의 번들로 묶고 최적화하여 사용할 수 있게 만들어주는 도구
- 의존성 관리 코드 최적화, 리소스 관리
