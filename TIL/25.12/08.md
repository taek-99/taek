# STATE


## Stage Management
- state
    - 앱 구동에 필요한 기본 데이터
- view
    - 상태를 선언적으로 매핑하여 시각화
- actions
    - 정의된 동작
- 단방향 흐름이다

## Pinia
- vue의 공식 상태 관리 라이브러리
- 트리 계층 구조에 관계 없이 상태에 접근하거나 기능을 사요할 수 있음
- 여러 컴포넌트가 함께 사용해야 하는 공통 데이터를 중앙 저장소에서의 통합 관리를 도와줌
- 어떤 컴포넌트든 이 중앙 저장소에 직접 접근하여 데이터를 읽거나 수정할 수 있음

### Pinia 구성 요소: store
- 공통 데이터를 관리하는 중앙 저장소
- 모든 컴포넌트가 공유하는 상태
- 변수 이름은 use~~Store 패턴으로 사용하는 것을 권장

## Pinia 구성요소: getters
- 계산된 값
- state를 기반으로 파생된 값을 정의하는것
- computed와 똑같은 역할

## Pinia 구성요소: actions
- state를 변경하는 역할
- methods과 같은 역할을 함

## Pinia 구성 요소: 반환 값
- 반드시 반환행야함

## Pinia 구성 요쇼: plugin
- 애플리케이션의 상태 관리에 필요한 추가기능을 제공하거나 확장하는 도구나 모듈
