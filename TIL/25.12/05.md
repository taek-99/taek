# 관통

## 프로젝트 기획과 설계

### 기획과 설계
- 기획: 프로젝트 목표와 전략을 수립하는 과정
- 설계: 기획된 목표를 구현하기 위한 구조와 방법을 정의하는 과정

- 요구사항 분석
    - 사용자와 이해 관계자의 필요, 요구를 수집하고 명세화하는 과정이 필요
    - 기능적 요구사항
    - 비기능적 요구사항    
    - 핵심 기능 식별
        - 시스템이 꼭 해야 할 기능 (mvp)과 추가될 수 있는 기능을 구분
    - 사용자 정의
        - 사용자 유형을 설정
    - 제약 사항 파악
        - 기술, 일정, 예산, 법적 요건

### 아키텍처와 기술 스택 결정
- 유지 보수성 확장성 확보
    - 팀 역할 분담 명확화

- 스택 선택 기준
    - 학습 곡선
    - 커뮤니티 지원
    - 성능

- 라이브러리 선정

- 프로젝트 구조 및 코드 컨벤션
    - 코드 가독성, 유지보수성을 확보
    - 팀원 간 협업 시 혼선을 최소화하여 업무의 효율화



## 프로젝트 세부 설계

### Vue 설계
- 라우팅 설계
    - 자원의 식별
    - 자원의 행위
    - 자원의 표현
    - RESTFUL API: 자원을 정의하고 자원에 대한 주소를 지정

- 컴포넌트 분리 및 책임 정의
    - VIEW부분과 UI 부분 구분
    - 하나의 컴포넌트는 하나의 역할만 책임

- API 설계 및 연동 구조
    - Back-End API 문서화
    - AJAX 기술 결정

- UI/UX 스타일 가이드
    - 디자인 시스템
    - 전역 CSS vs Scoped CSS
    - 공통 레이아웃 컴포넌트

- 문서화
    - 일정 계획 수림
    - WBS (Work Breakdown Structure)
    - 간트 차트
        - 프로젝트 일정을 타임라인으로 나열하여, 프로젝트 기간, 진행률을 나타내는 표현방법
