# Java

## event object
- 돔에서 이벤트가 발생하면, 브라우저는 해당 이벤트에 관한 정보를 담은 '이벤트 오브젝트'를 자동으로 생성
- 종류
    - mouse
    - input
    - keyboard

- 요소 가져오기 -> 이벤트 함수 만들기 -> 연결하기

## event handler
- 특정 이벤트가 발생했을 때 실행되는 콜백함수

## .addEventListener()
- 특정 DOM요소에 지정한 이벤트가 발생했을 때 실행할 이벤트 핸들러를 등록하는 메서드


## 이벤트 등록
- DOM 요소: HTML 문서의 각 태그를 하나의 객체로 변환한것
- 수신할 이벤트: 무언가 일어났다는 신호 또는 사건
- 핸들러: 특정 이벤트가 발생했을때 실행되는 함수

## 이벤트 핸들러에서의 this
- 일반 함수를 핸들러로 사용 시, this는 이벤트 리스너가 연결된 요소를 가리킴

## 버블링
- 한 요소에 이벤트가 발생하면, 해당 요소의 핸들러가 동작한 후 이어서 부모 요소의 핸들러가 동작하는 현상
- 가장 최상단의 조상 요소를 만날 때까지 이 과정이 반복되면서 요소 각각에 할당된 핸들러가 동작
- 이벤트가 제일 깊은 곳에 있는 요소에서 시작해 부모 요소를 거슬러 올라가며 발생하는게 버블 같아서

- event.currentTarget
    - 현재 요소
- event.target
    - 이벤트가 발생한 가장 안쪽의 요소를 참조하는 속성
    - 실제 이벤트가 시작된 요소

## 캡쳐링
- 이벤트가 최상위 조상에서 타겟 요소까지 하위로 전파되는 단계(버블링과 반대)
