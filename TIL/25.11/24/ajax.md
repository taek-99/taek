## 동기와 비동기

## sync 특징
- 시작 순서대로 처리
- 앞의 작업이 먼저 끝나야만 다음 작업 시작
- 장점
    - 단순하고 예측 가능한 흐름
- 단점
    - 시간이 오래걸림
    - 자원 낭비

## Async 특징
- 병렬적 수행
- 당장 처리를 완료할수 없는 작업들은 백그라운드에서 실행
- 장점
    - 효율성
    - 사용자 경험 향상
- 단점
    - 코드의 복잡성 증가

- Shingle Thread 언어인 자바스크립트
    - js는 한번에 하나의 일만 수행할 수 있는 싱글 스레드 언어로 동시에 여러작업 처리 x

## JS런타임
- 비동기 처리를 할 수 있도록 도와주는 환경이 필요
- JS 엔진의 콜스택
    - 코드가 실행되면 함수 호출이 순서대로 쌓이는 작업 공간
- Web API
    - 시간이 걸리거나 언제 실행될 지 모르는 비동기 작업들을 처리하는 곳
    - 브라우저에 제공하는 런타임 환경
- Task Queue
    - Web API에서 처리가 완료된 작업들이 순서대로 줄을 서서 기다리는 대기열
- Event Loop
    - 콜스택이 비어있는지 계속해서 확인하면서 비는 순간 TaskQueue에서 가장 오래된 작업을 콜스택으로 보냄

## Ajax
- 비동기적인 웹 애플리케이션 개발을 위한 기술
- 웹 페이지 전체를 새로고침하지 않고, 백그라운드에서 서버와 데이터를 주고받는 비동기 통신 기술

- 목적
    - 비동기 통신
    - 부분 업데이트
    - 서버 부하 감소


## Axios
- 브라우저와 Node.js환경에서 모두 사용할 수 있는 Promise 기반의 HTTP 클라이언트 라이브러리
- 간편하게 Ajax 통신을 할 수 있도록 도와주는 JS 라이브러리
- 간편하게 API를 제공하며 Promise 기반의 비동기 요청을 처리
- 주로 웹 애플리케이션에서 서버와 통신할 때 사용

## Axios 동작
- XHR 객체 생성 및 요청
- 응닫 데이터 생성
- JSON 데이터 응답
- Promise 객체를 활용해 DOM 조작

## Axios 설치 및 사용
- CDN 방식 진행 예정
- axios 객체를 활용해 요청을 보낸 후 응답 데이터 promise 객체를 받음
- 비동기 작업의 최종완료와 그 결과값을 나타냄

- then(): 작업이 성공
- catch(): 작업이 실패


## Axios 가본 구조
- 성공처리
    - 서버로부터 받은 응답 데이터를 처리
    - then 메서드를 사용해서 성공했을때의 수행할 로직을 작성

- 실패 처리


## 고양이 사진 가져오기
- 버튼 누르기
- 고양이 이미지 요청
- 요청이 처리되어 응답이 오면
- 응답에 따른 이미죄


## 콜백, 프로미스
- 비동기 콜백
    - 비동기적으로 처리되는 작어비 완료되었을때 실행되는 함수
    - 연쇄적으로 발생하는 비동기 작업을 순차적으로 동작할 수 있게함

    - 한계
        - 비동기 콜백 함수는 보통 어떤 기능의 실행결과를 받기 위해 사용됨
        - 이로인해 콜백 지옥 발생
    - 콜백 함수는 비동기 작업을 순차적으로 실행할 수 있게 하는 반드시 필요한 로직

## then& catch의 체이닝
- axios로 처리한 비동기 로직은 항상 promise 객체를 반환
- 즉, then과 catch는 모두 항상 promise객체를 반환

- then 체이닝의 장점
    - 가독성
    - 에러처리
    - 유연성
    - 코드관리

## promise가 제공하는 이점
- 실행 순서의 보장
    - 콜백 함수
    - promise

- 체이닝을 통한 연속적인 비동기 처리
- 에러처리의 일원화
