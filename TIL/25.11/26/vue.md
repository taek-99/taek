# VUE

## Frontend Development
- 웹 사이트와 웹 애플리케이션의 사용자 인터페이스와 사용자 경험을 만들고 디자인하는 것
- HTML, CSS, JavaScript 등을 활용하여 사용자가 직접 상호작용하는 부분을 개발

## CSF
- 클라이언트 측에서 UI와 상호작용을 개발하기 위해 사용되는 JavaScript 기반 프레임워크

- 동적이고 반응적인 웹 애플리케이션 개발
- 코드 재사용성 증가
- 개발 생산성 향상

## SPA 
- Single Page Application
- 단알 페이지에서 동작하는 웹 애플리케이션

- 작동원리
    - 최초 로드 시, 어플리케이션에 필요한 주요 리소스를 다운로드
    - 페이지 갱신에 대해 필요한 데이터만을 비동기적으로 전달받아 화면의 필요한 부분만 동적으로 갱신
    - JavaScript를 사용하여 클라이언트 측에서 동적으로 콘텐츠를 생성하고 업데이트
        - CSR

## CSR
- Client Side Rendering
- 클라이언트에서 콘텐츠를 렌더링 하는 방식

- 작동원리
    - 사용자가 웹사이트에 요청을 보냄
    - 서버는 최소한의 html과 js 파일을 클라이언트로 전송
    - 클라이언트는 html과 js를 다운 받음
    - 브라우저가 js를 실행하여 동적으로 페이지 콘텐츠를 생성
    - 필요한 데이터는 api를 통해 서버로부터 비동기로 작동

## CSR과 SPA의 장점
- 빠른 페이지 전환
- 사용자 경험
- 프론트와 백의 명확한 정리

## CSR과 SPA의 단점
- 느린 초기 로드 속도
- SEO 문제


## MPA/ SSR
- MPA
    - 여러개의 HTML파일이 서버로부터 각각 로드
    - 사용자가 다른 페이지로 이동할때마다 새로운 HTML 파일이 로드

- SSR
    - 서버에서 화면을 렌더링 하는 방식
    - 모든 데이터가 담긴 HTML을 서버에서 완성 후 클라이언트에게 전달


## Vue
- 사용자 인터페이스를 구축하기 위한 JS 프레임워크
- 레고 블록처럼 가능한 부품으로 화면을 조립하고, 데이터가 바뀌면 화면도 자동으로 바뀌는 반응성
- 배우기 쉽고 직관적이면서도 강력해, 초보자부터 전문가까지 폭넓게 사용하는 인기있는 기술


## Vue 사용 이유
- 낮은 학습 곡선
- 확장성과 생태계
- 유연성 및 성능
- 주목 받는 CSR
