
## 복습
- DOM 조작
    - 선택 메서드
        - document.querySelector(selector)
        - document.querySelectorALL(selector)
        - id => #, class => ., 일반 요소 => 요소이름

    - 조작 메서드
        - 클래스조작: classList, remove, toggle
        - HTML 내부 컨텐츠 조작: textConetent
        - 요소를 직접 조작: createElement, appendChild. removeChild
        - 스타일 직접 조장: style.color, style.fontSize

- JS 문법
    - let
        - 재할당O, 재선언X
    - const 
        - 재할당X, 재선언X
    - 호이스팅 불가

    - for in 객체의 키를 순회, for of 객체의 벨류를 순회
    
    - 함수 선언식(가독성이 좋다, 호이스팅이 된다.)
    - 함수 표현식(호이스팅이 안된다X, 스코프 관리가 용이)

    - null: 값이 없음, undefined: 값이 할당 되지 않음

    - this
        - 파이썬에서의 self, 호출한 객체를 의미함
        - 일반함수에서의 this, 객체에서의 메소드에서의 this가 달랐다.
            => 일반함수 this가 전역 객체를 의미한다. 근데 호출한 객체를 나타내고 싶을때 화살표 함수를 사용

    - forEach, map, filter
