# 시험대비

## 결합도

- 자료(Data): 값 전달, 결합도 제일 낮음
- 스탬프(Stamp): 배열, 오브젝트 전달
- 제어(Control): 제어요소 전달
- 외부(External): 다른 모듈에서 만든 변수 참조
- 공통(Common): 전역변수
- 내용(Content): 모듈내부 변수 기능 사용

## 응집도

- 우연적 응집도(Coincidental): 모듈 내부의 각 구성들이 연관이 없을경우
- 논리적 응집도(Logical): 유사한 성격을 갖거나 특정하게 분류되는 처리 요소
- 시간적 응집도(Temporal): 같은 시간에 수행, 특정 시간해 처리
- 절차적 응집도(Procedural): 관련된 기능들을 순차적으로 수행
- 통신적 응집도(Communication): 동일한 입력, 출력
- 순차적 응집도(Sequential): 출력값을 입력값으로 사용
- 기능적 응집도(Functional): 단일한 목적 수행
