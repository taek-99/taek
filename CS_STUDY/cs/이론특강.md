## 무결성 제약 조건
- 개체 무결성: 기본키는 중복되지 않고, Null값을 가질 수 없다.
- 참조 무결성: 외래키는 Null이거나, 참조 릴레이션의 기본키와 일치해야한다.
    - 제한
    - 연쇄
- 도메인 무결성: 모든 속성 값은 정의된 도메인에 속해야 한다
- 고유 무결성: 특정 속성 값은 중복되지 않고 유일해야 한다
- 키 무결성: 릴레이션은 키를 가져야 한다
- 릴레이션 무결성: 삽입, 삭제, 갱신 등의 연산은 릴레이션의 무결성을 해치면 안된다.

## OSI 7계층
- 응용: 사용자와 프로그램 간 인터페이스
- 표현: 서로 다른 데이터 표현 형식 간 변환 담당

- 전송: 양 끝단 간 신뢰성 있는 데이터 전송을 담당
    - 프로토콜: TCP, UDP
- 네트워크: 데이터를 목적지까지 라우팅하고 전송

- 데이터링크: 인접한 노드 간의 신뢰성 있는 정보 전송
    - 장비: 스위치, 브리지
- 물리: 전기적 신호로 변환하여 전송
    - 장비: 통신케이블, 랜카드(NRC), 리피터, 허브

## HDLC
- 데이터 링크 계층에서 사용되는 비트 지향 프로토콜
- 프레임 구조: 플래그, 주소필드, 제어필드, 데이터, FCS
- 프레임 유형
    - 정보 프레임: 데이터 전송을 위한 프레임
    - 감독 프레임: 오류 검출 및 흐름 제어를 위해 사용
    - 비순서 프레임: 추가적인 제어 목적
- 전송 모드
    - NRM: 주국과 하나 이상의 종국
    - ABM: 무든 단말이 주국 기능 제어 수행
    - ARM: 주국이 통신을 제어, 종국도 자체적으로 데이터 전송
