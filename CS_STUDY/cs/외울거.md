### 인터페이스 보안 프로토콜
- 네트워크 영역: IPSec, SSL, S-HTTP
- 애플리케이션 영역: 시큐어 코딩
- DB 영역: 암호화(API방식, Plugin방식, TDE방식)


### 보안 프로토콜
- SSL/ TLS
    - 웹 브라우저와 서버간에 암호화된 연결을 제공
- IPSec
    - IP 네트워크에서 안전하게 데이터를 전송하는데 사용되는 프로토콜
    - AH: 무결성, 인증 제공
    - ESP: 무결성, 인증, 기밀성 제공
- SSH
    - 원격 컴퓨터에 안전하게 접속하고 명령을 실행하는데 사용되는 프로토콜
- PGP
    - 이메일과 같은 데이터를 암호화하고 디지털 서명하는데 사용

### 인터페이스 구현
- AJAX: 비동기 방식으로 데이터를 교환
- SOAP
    - 구성: SOAP(메세지 교환), UDDI(업체 목록 등록), WSDL(서비스 세부사항)
    - 교환 프로토콜: HTTP, HTTPS, SMTP
- REST
    - 구성: 자원(URI), 행위(GET/POST/PUT/DELETE), 표현(데이터 표현)

- 경로 검증: 모든 가능한 경로 검사
- 조건 검증: 조건식 검사

### DRM
- 디지털 콘텐츠의 불법 사용을 제한하고, 승인된 사용자에게만 콘텐츠 사용을 허용하는 기술
- 콘텐츠 제공자: 콘텐츠를 제공하는 저작권자
- 콘텐츠 분배자: 암호화된 콘텐츠 제공
- 패키저: 콘텐츠를 메타 데이터와 묶는 기능
- 보안 컨테이너: 안전한 유통을 위한 전자적 보안 장치
- DRM 컨트롤러: 콘텐츠의 이용권한을 통제
- 클리어링 하우스: 키 관리 및 라이선스 발급 관리

### 형상 관리 절차
- 형상 식별: 관리해야할 항목 구분
- 형상 통제: 변경 요청 검토/ 형상 통제 위원회
- 형상 감사: 변경에 대한 검토
- 형상 기록: 변경 사항과 처리 과정을 기록

### AAA
- 인증(Authentication): 사용자의 신원 확인
- 권한 부여(Authorization): 권한과 서비스를 허용
- 계정관리(Accounting): 사용자의 자원 사용정보를 수집

### 인증방식
- Cookie/Session 방식
- 토큰인증방식(JWT)
- OAuth: 이용자의 웹 서비스에 대한 제한된 접근 권한을 안전하게 부여
- SSO
- 커버로스: 사용자와 서비스 간의 인증을 안전하게 관리
- 아이핀: 주민등록번호 대체 수단

### 접근통제
- MAC: 강제적 접근 통제
- DAC: 임의적 접근통제
- RBAC: 역할별 기반 접근 통제

### 접근통제 모델
- 벨-라파둘라모델: 기밀성
- 비바 모델: 무결성
- 클락-윌슨 모델: 무결성에 중점을 둔 상업용 모델
- 만리장성 모델: 이해 충돌을 방지

### IP관련 기타 기술
- NAT: 사설 IP 주소와 공인 IP주소간의 변환
- DNS: 도메인 이름을 IP 주소로 변환하거나 그 반대의 작업을 수행
- Qos: 네트워크 자원을 효율적으로 사용하여 특정 트래픽의 성능과 속도를 보장하는 기술
- VPN: 공용 네트워크를 통해 사설 네트워크에 안전하게 접속
- DHCP: 네트워크 장치에 자동으로 IP 주소를 할당하는 프로토콜

### 블랙박스 테스트 기법
- 동등 분할 기법 Equiavlence: 입력자료에 초점을 맞춰 테스트 케이스를 만들어 검사
- 경곗값 분석 기법 Boundary Value: 입력 조건의 경계값을 테스트 케이스로 선정
- 오류 예측 기법 Case Effect Graph: 입력 데이터 간의 관계와 출력
- 오류 예측 검사: 과거의 경험이나 테스터의 감각
- 비교 검사: 여러 버전에 동일한 테스트 제공

    - 결정 커버리지: 결정 포인트 내의 모든 분기문에 대해 수행

    - 다중 조건 커버리지: 가능한 조합을 100% 보장

### 서비스 공격 유형의 종류
- Dos
    - 스머프 어택
        - IP와 ICMP
    - Ping of Death
        - 규정 크기 이상의 YCMP
    - Teardrop Attack
        - 조립 관련 어쩌구
    - LAND Attack
        - 출발지랑 도착지 주소가 똑같음

- DDos
    - 스머프
        - 과도한 트래픽으로 인한 서비스 장애

### 공격 유형의 종류
- Worm: 자가 복제, 네트워크 통해 스스로
- 트로이 목마: 유용한 소프트웨어로 가장한 악성 프로그램
- 백도어: 보안 시스템을 우회하여
- 바이러스: 파일이나 다른 실행 가능한 코드에 자신을 불어넣음
- 랜섬웨어: 파일을 암호화하여 접근을 못하게함
- 스파이웨어: 사용자 동의 없이
- 에드웨어: 광고를 무분별하게 보여주는
- APT: 지속적으로
- 제로데이: 아직 알려지지 않은
