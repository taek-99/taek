### 소프트웨어 아키텍처 4+1뷰
- 논리뷰: 시스템의 기능적 요구사항
- 구현뷰: 모듈의 구성과 개발자
- 프로세스 뷰: 프로그램 실행 시의 시스템
- 배치 뷰: 시스템의 물리적 배치
- 유스케이스 뷰: 아키텍처

### UNL 관계
- 일반화 관계: 상속
- 연관 관계: 관련된 관계
- 의존 관계: 짧은 시간만 사용
- 실체화 관계: 추상 메서드를 오버라이딩

### 결합도
- 자료: 값
- 스탬프: 배열
- 제어: 제어 요소
- 외부: 다른 모듈 변수
- 공유: 전역 변수
- 내용: 다른 모듈 기능

### 응집도
- 우연적: 서로 연관 없음
- 논리적: 유사한 성경
- 시간적: 같은 시간 기능 수행 
- 절차적: 순차적으로 진행
- 통신적: 입력값과 출력값 동일 
- 순차적: 출력값이 입력값
- 기능적: 단일한 목적 수행

### 형상 관리 절차
- 형상 식별: 관리해야할 항목 구분
- 형상 통제: 변경 요청 검토/ 형상 통제 위원회
- 형상 감사: 변경에 대한 검토
- 형상 기록: 변경 사항과 처리 과정을 기록

### AAA
- 인증(Authentication): 사용자의 신원 확인
- 권한 부여(Authorization): 권한과 서비스를 허용
- 계정관리(Accounting): 사용자의 자원 사용정보를 수집

### 인증방식
- Cookie/Session 방식
- 토큰인증방식(JWT)
- OAuth: 이용자의 웹 서비스에 대한 제한된 접근 권한을 안전하게 부여
- SSO
- 커버로스: 사용자와 서비스 간의 인증을 안전하게 관리
- 아이핀: 주민등록번호 대체 수단

### 접근통제
- MAC: 강제적 접근 통제
- DAC: 임의적 접근통제
- RBAC: 역할별 기반 접근 통제

### 접근통제 모델
- 벨-라파둘라모델: 기밀성
- 비바 모델: 무결성
- 클락-윌슨 모델: 무결성에 중점을 둔 상업용 모델
- 만리장성 모델: 이해 충돌을 방지

### IP관련 기타 기술
- NAT: 사설 IP 주소와 공인 IP주소간의 변환
- DNS: 도메인 이름을 IP 주소로 변환하거나 그 반대의 작업을 수행
- Qos: 네트워크 자원을 효율적으로 사용하여 특정 트래픽의 성능과 속도를 보장하는 기술
- VPN: 공용 네트워크를 통해 사설 네트워크에 안전하게 접속
- DHCP: 네트워크 장치에 자동으로 IP 주소를 할당하는 프로토콜

### 블랙박스 테스트 기법
- Equiavlence: 입력자료에 초점을 맞춰 테스트 케이스를 만들어 검사
- Boundary Value: 입력 조건의 경계값을 테스트 케이스로 선정
- Case Effect Graph: 입력 데이터 간의 관계와 출력
- 오류 예측 검사: 과거의 경험이나 테스터의 감각
- 비교 검사: 여러 버전에 동일한 테스트 제공
