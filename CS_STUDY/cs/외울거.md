### AAA
- 인증(Authentication): 사용자의 신원 확인
- 권한 부여(Authorization): 권한과 서비스를 허용
- 계정관리(Accounting): 사용자의 자원 사용정보를 수집

### 인증방식
- Cookie/Session 방식
- 토큰인증방식(JWT)
- OAuth: 이용자의 웹 서비스에 대한 제한된 접근 권한을 안전하게 부여
- SSO
- 커버로스: 사용자와 서비스 간의 인증을 안전하게 관리
- 아이핀: 주민등록번호 대체 수단

### 접근통제
- MAC: 강제적 접근 통제
- DAC: 임의적 접근통제
- RBAC: 역할별 기반 접근 통제

### 접근통제 모델
- 벨-라파둘라모델: 기밀성
- 비바 모델: 무결성
- 클락-윌슨 모델: 무결성에 중점을 둔 상업용 모델
- 만리장성 모델: 이해 충돌을 방지

### IP관련 기타 기술
- NAT: 사설 IP 주소와 공인 IP주소간의 변환
- DNS: 도메인 이름을 IP 주소로 변환하거나 그 반대의 작업을 수행
- Qos: 네트워크 자원을 효율적으로 사용하여 특정 트래픽의 성능과 속도를 보장하는 기술
- VPN: 공용 네트워크를 통해 사설 네트워크에 안전하게 접속
- DHCP: 네트워크 장치에 자동으로 IP 주소를 할당하는 프로토콜

### 블랙박스 테스트 기법
- Equiavlence: 입력자료에 초점을 맞춰 테스트 케이스를 만들어 검사
- Boundary Value: 입력 조건의 경계값을 테스트 케이스로 선정
- Case Effect Graph: 입력 데이터 간의 관계와 출력
- 오류 예측 검사: 과거의 경험이나 테스터의 감각
- 비교 검사: 여러 버전에 동일한 테스트 제공

### 애플맄이션 테스트 유형
- 프로그램 실행 여부
    - 동적
    - 정적
- 테스트 기법
    - 화이트박스
    - 블랙박스
- 테스트에 대한 시각
    - 검증
    - 확인

### 테스트 기법
- 단위 테스트
    - 정적
    - 동적
- 통합
    - 상향식: 드라이버
    - 하향식: 스텁
    - 빅뱅
- 시스템
    - 기능
    - 비기능
- 인스 
    - 알파
    - 베타

### 테스트 목적
- 회복: 고의로 실패
- 안전: 보안적인 결함 점검
- 강도: 과부하 테스트
- 성능: 응답하는 시간, 처리량
- 구조: 소스 코드의 복잡도
- 회귀: 변경 코드에 대한 결함
