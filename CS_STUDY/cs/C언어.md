# C언어
## C언어 기본구조

### C언어 기본 구조

- C언어는 본문 전에 처리하는 전처리 부분과 본문으로 구성되어 있다

### 전처리기

- 개념

    - 전처리기는 실행 파일을 생성하는 과정에서 소프 파일 내에 존재하는 전처리 지시문을 처리하는 작업이다.

- 전처리기 종류

    - #include

        - c언어 프로그램에 헤더 파일을 포함할 때 사용 하는 전처리기

    - #define

        - 메크로를 정의할때 사용하는 전처리기

## 식별자

### 식별자 표기법

- 카멜 표기법

    - 식별자 표기시 여러 단어가 이어지면 첫 단어시작만 소문자로 표시하고, 각 단어의 첫글자는 대문자로 표기하는 방법

- 파스칼 표기법

    - 식별자 표기시 여러 단어가 이어지면 각 단어의 첫 글자는 대문자로 지정하는 표기법

- 스네이크 표기법

    - 식별자 표기시 여러 단어가 이어지면 단어 사이에 언더바를 넣는 표기법

- 헝가리안 표기법

    - 식별자 표기시 두어에 자료형을 붙이는 표기법

## 변수

### 변수 유효범위

- 전역변수

    - 어떤 블록에도 속하지 않는 변수

- 지역 변수

    - 블록 내에서 선언하는 변수

- static 변수

    - 블록 내외부 상관없이 선언할 수 있느 ㄴ변수

    - static 변수는 선언할떄 static이라는 키워드를 붙여야함

    - 블록 상관없이 프로그램이 시작되면 변수가 생성되고 프로그램이 종료되면 변수가 소멸

## 표준 입출력 함수

### 표준 출력 함수

- printf는 지정된 포맷 스트링으로 데이터를 출력하는 함수

- 이스케이프 문자를 이용한 출력

    - 문자열 내에서 특수한 기능을 수행하는 문자

    - \n, \t등등

- 포맷 스트링을 이용한 변수 출력

    - 일반적으로 scanf를 통해 사용자로부터 입력을 받아들이거나 printf를 통해 결과를 출력하기 위하여 사용하는 형식

    - %c, %s, %u, %d, %o, %x, %e, %E, %f, %lf

- 포맷 스트링을 이용한 변수 상세 출력

    - 포맷 스트링을 이용해 정렬, 0 채우기, 출력할 공간 확보, 소수점 자릿수 표기를 지정할 수 있다.

    - [-] 

        - 붙이면 왼쪽정렬

        - 안붙였는데 [전체자리수]가 있으면 오른쪽 정렬

    - [0]

        - 전체 자릿수에서 앞에 빈자리만큼 0으로 채움

    - [전체자리수]

        - 전체자리수만큼 공간 확보

        - 소수점도 한자릿수로 포함됨

    - [소수점자리수]

        - 소수점이 출력

        - 실수형일때만 적용

### 표준 입력 함수

- scanf는 키보드로 입력받은 문자열에서 지정된 포맷 스트링으로 데이터를 읽는 함수이다.

### gets 함수

## 구조체

- 개념

    - 구조체는 사용자가 기본 자료형을 가지고 새롭게 정의할 수 있는 사용자 정의 자료형이다.

- 구조체 선언

    - 구조체는 구조체변수, 변수명 형태로 값을 가리킨다.

    - 구제체를 초기화 할때는 중괄호 {}안에 구조체 멤버의 선언 순서대로 값을 넣어 초기화한다.

- typedef 연산

    - 기존의 자료형에 새롭게 별칭을 부여하기 위한 연산이다.

## 공용체

- 개념

    - 공용체는 모든 멤버 변수가 하나의 메모리 공간을 공유하는 사용자 정의 자료형이다.

- 선언

    - 공용체는 공용체변수, 변수명 형태로 값을 가리킨다.

    - 공용체를 초기화 할때는 중괄호{} 안에 공용체 멤버중 하나만 초기화 할수 있다.

## 함수

### main 함수

- 개념

    - 프로그램이 실행하는 모든 프로그램의 시작

    - main 함수에 있는 명령어를 실행한다.

- 형태

    - 자료형 main(){}

    - void main() 일 경우 반환할 값이 없으므로 return;을 사용하거나 reurn자체를 사용하지 않는다.

## 사용자 정의 함수

- 사용자 정의 함수 개념

    - 사용자가 직접 새로운 함수를 정의하여 사용하는 방법

    - 사용자 정의함수에서 매개변수나 생성된 변수는 사용자 정의 함수가 종료되면 없어진다.


- 매개변수 전달 방법

    - Call by value

        - 변수의 값을 넘겨주고, 이 값은 새로운 공간에 할당되어 사용하는 방식

    - Call by Reference

        - 변수의 값이 아닌 변수가 사용 중인 메모리 공간의 주소를 넘겨주는 방식

## 포인터

- 개념

    - 포인터는 변수의 주솟값을 저장하는 공간

- 포인터 선언

    - 자료형 뒤에 *을 붙이면 주소를 저장하는 포이터 변수라는 의미이고, 일반 변수형에 &를 붙이면 해당 변수명의 주솟값이다.
