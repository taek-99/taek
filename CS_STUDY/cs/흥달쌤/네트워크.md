## 근거리 통신망

### LAN
- 가까운 거리에 한정된 네트워크
- 전송방식
    - 베이스 밴드: 가까운거리
    - 브로드 밴드: 변조하여 멀리 전송
- LAN 프로토콜
    - LLC: 흐름 제어, 오류처리
    - MAC: 물리적 전송 매체와의 연결방식 제어

### 802.X시리즈
- 1: LAN 전체 구성
- 2: LLC
- 3: CSMA/CD
- 4: 토큰 버스 네트워크
- 5: 토큰 링 네트워크
- 11: 무선 LAN(와이파ㅣㅇ)
- 15: 무선 개인 영역 네트워크(WPAN)

### HDLC
- 데이터 링크 계층에서 사용되는 비트 지향 프로톨콜
- 프레임 구조: 플래그, 주소필드, 제어필드, 데이터, FCS
- 프레임 유형
    - 정보 프레임: 데이터 전송을 위함
    - 감독 프레임: 오류 검출 및 제어흐름
    - 비순서 프레임: 추가적인 제어 목적
- 전송모드
    - 정규 응답 모드(NRM): 주국과 하나 이상의 종국으로 구성
    - 비동기 균형 모드(ABM): 모든 단말이 주국기능을 수행
    - 비동기 응답 모드(ARM): 주국이 통신을 제어, 종국도 자체적으로 데이터 전송

## 인터넷

### URI구조
- 스키마: 통신 방식이나 프로토콜
- 도메인: 통신할 서버의 도메인명
- 포트: 서버의 특정 프로세스 번호
- Path: 리소스의 위치
- 쿼리스트링: 서버로 전달되는 데이터
- 플라그먼트: 서브 리소스에 바로 접근할 때 사용
- 어쏠리티: 사용자 정보, 호스트, 포트 번호

### IP
- 인터넷에서 장치를 식별하기 위한 고유한 번호
- IPv4
    - 32비트 크기
    - 주소분류: 유니캐스트, 멀티캐스트, 브로드캐스트
    - A클래스(0), B클래스(10), C클래스(110)
- IPv6
    - 128비트 크기, 16비트씩 8부분
    - 주소분류: 유니캐스트, 멀티캐스트, 애니캐스트

### IPv4/ IPv6 전환 기술
- 듀얼 스택: 둘다 지원
- 터널링: IPv6패킷을 IPv4패킷 속에 캡슐화하여 전송
- 주소변환: IPv6시스템과 IPv4시스템 간의 헤더 변환

### IP 관련 기술
- NAT: 사설 IP와 공인 IP 주소 간의 변환
- DNS: 도메인 이름을 IP주소로 변환하거나 그 반대 작업을 수행
- QoS: 트래픽의 성능과 속도를 보장하는 기술
- VPN: 공용 네트워크를 통해 사설 네트워크에 접속
- DHCP: IP주소를 자동으로 할당하는 프로토콜

## 프로토콜
- 데이터 교환을 위한 표준화된 통신 규약
- 프로토콜의 기본 요소
    - 구문
    - 의미
    - 타이밍

### 흐름제어
- 수신측의 처리 능력에 맞춰 송신 측에서 데이터의 전송량이나 속도를 조저랗는 기능
- 방식
    - STOP AND WAIT 방식
    - SLIDING WINDOW 방식
    - 피기배킹: 정보 프레임과 응답 프레임을 동시에 전송하는 방식

### 오류제어
- 데이터 전송 중 발생하는 오류를 검출하고, 이를 정정하는 기능
- 방식
    - Stop and Wait ARQ: 데이터 전송 후, 수신 측의 응답을 받을 때 사용 
    - Go Back N ARQ: 오류가 발생한 지점부터 모든 데이터를 재전송
    - Selective Reapeat ARQ: 오류가 발생한 특정 프레임만 재전송
    - Adaptive ARQ: 네트워크 상태에 따라 데이터 프레임 크기를 조정

### 전송 오류 제어 방식
- 전진 오류 수정
    - 재전송 요구 없이 스스로 오류를 검출하고 수정하는 방식
    - 해밍코드, 상승 코드
- 후진 오류 수정
    - 오류가 발견되면 송신 측에 재전송을 요구하는 방식
    - 패리티 검사, CRC, 블록합

### 라우터
- 패킷의 경로 설정과 스위칭을 담당하는 장비
- 정적 라우팅
- 동적 라우팅
    - 내부(IGP)
        - 거리백터
            - RIP
        - 링크 상태
            - OSPF
    - 외부(EGP)

### 주요 라우팅 프로토콜
- RIP
    - 거리 백터 알고리즘 기반의 라우팅 프로토콜
    - 최대 15홉까지 지원
    - 30초마다 라우팅 정보를 인접 라우터와 교환
- OSPF
    - 링크 상태 기반의 라우팅 프로토콜
    - 링크 상태 변화시에만 라우팅 정보를 전송
- BGP
    - 대규모 네트워크에 적합한 라우팅 프로토콜

## OSI 7계층
- 응용: 응용프로그램
- 표현: 데이터 표현 형식 간 변환담당
- 세션: 연결 상태
- 전송: 양 종단간 신뢰성 있는 데이터 전송(세그먼트)
- 네트워크: 빠른 전송(패킷)
- 데이터링크: 인접한 노드 간 신뢰성 있는 정보 전달(프레임)
- 물리: 전기적 신호로 전달(비트)

- 응용+표현+세션: data
- data+세션: h/d
- h/d+세그먼트: 패킷
- 패킷+헤더: 프레임

### OSI 7계층 장비
- 네트워크 계층: 라우터, L3 스위치
- 데이터 링크 계층: 스위치, 브리지
- 물리계층: 통신케이블, 랜카드, 리피터, 허브

### 백본
- 대규모 패킷 통신망
- 스위치 종류
    - L2: MAC 주소 기반
    - L3: IP주소 기반
    - L4: 부하 분산
    - L7: 보안 장비에 활용

## TCP/IP
- 인터넷에서 가장 널리 사용되는 표준 프로토콜 모델
- 응용
    - TCP: HTTP, SSH(22번)
    - UDP: DNS, DHCP
- 전송: TCP, UDP
- 인터넷: IP, ICMP
    - ARP: IP를 MAC으로
    - RARP: MAC을 IP로
- 네트워크 엑세스: 엑스트라넷, X.25

### TCP/IP 특징
- IP
    - 데이터를 송수신 하는데 사용
    - 비신뢰성/ 비연결성
- TCP
    - 연결형 서비스를 제공
    - 신뢰성 있음
