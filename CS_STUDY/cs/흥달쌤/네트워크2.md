## 다중화
- 하나의 통신 회선을 여러 가입자가 사용
- 다중화기
    - 주파수 분할
    - 시분할(동기/ 비동기) 
    - 코드 분할
    - 파장 분할
    - 공간 분할
- 역다중화기
    - 하나의 고송 통신으로 여러개의 저속
- 집중화기 
    - 여러개의 저속으로 하나의 고속

## LAN
- 가까운 거리
- 전송방식
    - 베이스밴드: 가까운거리
    - 브로드 밴드: 변조하여 전송
- LAN 프로토콜
    - LLC: 흐름제어, 오류 처리
    - MAC: 물리적 전송 매체와의 연결방식 제어

## 802
- 802.1: LAN
- 802.2: LLC
- 802.3: CSMA/CD
- 802.4: 토큰버스
- 802.5: 토큰 링 네트워크
- 802.11: 와이파이
- 802.15: WPAN

## HDLC
- 데이터링크 계층에서 사용되는 비트 지향
- 프레임구조: 플래그, 주소필드, 제어필드, 데이터, FCS
- 프레임 유형
    - 정보 프레임: 데이터 전송을 위한 프레임
    - 감독 프레임: 오류 검출 및 흐름 제어를 위해 사용
    - 비순서 프레임: 추가적인 제어 목적
- 전송 모드
    - 정규 응답 모드(NRM): 주국과 하나 이상의 종국
    - 비동기 균형 모드(ABM): 모든 단말이 주국기능
    - 비동기 응답 모드(ARM): 주국이 통신 제어, 종국도 가능

## URI
- 스키마: HTTP 맨앞
- 도메인: NAVER
- PORT: 서버의 특정 번호
- PATH: NAVER 뒤
- 쿼리스트링: ?뒤
- 플래그먼트: 서브 리소스에 바로 접근
- 어쏘리티: 사용자 정보

## IP
- 인터넷에서 장치를 식별
- IPv4
    - 32비트
    - 주소 분류: 유니, 멀티, 브로드
- IPv6
    - 128비트, 16비트씩 8개
    - 유니, 멀티, 애니

## IPv4/ IPv6 전환
- 듀얼 스택: 둘다 지원
- 터널링: 패킷을 캡슐화
- 주소변환

## IP 관련 기술
- NAT: 사설 IP와 공인 IP 주소 변환
- DNS: 도메인 이름으 IP 주소로 변환하거나 그 반대 작업
- Qos: 트래픽의 성능과 속도를 보장
- VPN: 사설 네트워크
- DHCP: IP 주소를 자동으로 할당

## 흐름제어
- 방식
    - Stop and Wait 방식
    - Sliding Window 방식

## 오류제어
- Stop and Wait ARQ: 수신 응답시 기다림
- Go Back N ARQ: 오류 발생한 지점부터 모두 재전송
- Selective Reapeat ARQ: 오류가 발생한 시점만
- Adaptive ARQ: 네크워크 상태에 따라

## 전송 오류 제어 방식
- FEC
    - 재전송 요구 없음
    - 해밍 코드, 상승 코드
- BEC
    - 오류가 발견시 재전송
    - 패리티 검사, CRC, 블록합

## OSI 7계층
- 응용 계층: 응용 프로그램
- 표현 계층: 데이터 표현 형식 변환
- 세션 계층: 연결 상태
- 전송 계층: 양 종단 간 신뢰성 있는 데이터(세그먼트)
- 네트워크 계층: 빠른 전송(패킷)
- 데이터링크: 인접한 노드(프레임)
- 물리 계층: 전기적 신호(비트)

## OSI 7계층 장비
- 네트워크 장비: 라우터, L3
- 데이터 링크: 스위치, 브리지
- 물리 계층: 통신 케이블, 랜카드, 리피터, 허브

## 백본
- 대규모
- 스위치 종류

    - L4: 부하 분산
    - L7: 보안 장비
