# 운영체제

## 운영체제 기초

### 기억장치
- 데이터를 저장하는 장치
- 종류
    - 레지스터
    - 캐시메모리
    - 주기억장치
    - 보조기억장치
    - 연관메모리

### 시스템 소프트웨어
- 제어프로그램
    - 감시 프로그램
    - 작업 관리 프로그래
    - 데이터 관리 프로그램
- 처리 프로그램
    - 서비스
    - 문제
    - 언어번역

### 운영체제 운용기법
- 일괄처리시스템: 여러 작업을 묶어서 처리
- 실시간처리시스템: 요청 작업을 즉시 처리
- 다중 프로그래밍 시스템: 여러 프로그램이 동시에 실행
- 시분할시스템: 시간을 분할하여 시스템을 공유
- 다중처리시스템: 여러 cpu를 이용해서 처리
- 다중모드시스템: 운용기법을 혼합해서 사용

### 파일 디스크립터
- 프로세스가 파일에 접근할 때 사용하는 구조

### UNIX 구성
- 커널: 시스템 관리 기능수행
- 쉘: 명령어 해석기
- 유틸리티 프로그램

### 유닉스 파일 시스템
- 부트 블록: 부팅시 필요한 코드 저장
- 슈퍼 블록: 전체 파일 시스템에 대한 정보 저장
- I-node 블록: 파일의 정보가 저장
- 데이터 블록: 실제 파일 데이터가 저장

### 퍼미션
- 권한별 값: 751
- 권한 변경: chmod
- umask: 접근 권한 마스크
- 소유주 변경: chown

### 기억장치 관리 전략
- 반입 전략: 요구반입, 예상반입
- 배치 전략: 최초적합, 최적적합, 최악적합
- 교체 전략: FIFO, OPT, LRU, LFU, NUR, SCR

## 메모리 관리

### 단편화
- 주기억장치에 프로그램을 할당하고 반납하는 과저엥서 발생하는 빈공간
- 종류
    - 내부 단편화: 주기억장치에 남은공간
    - 외부 단편화: 할당되지 못하고 남은 공간
- 단편화해결
    - 통합:
    - 압축:
    - 재배치 기법:

### 가상기억장치
- 보조기억 장치의 일부를 주기억장치처럼 사용하는 기법
- 블록분할 방법
    - 페이징 기법: 같은 크기 블록으로 분할, 내부 단편화 발생
    - 세그먼테이션: 가변 크기로 분할, 외부 단편화 발생
- 기타관리사항
    - 페이지 부재
    - 지역성
    - 워킹셋
    - 스래싱: 프로세스 처리시간보다 페이지 교체시간이 더 많이 소요되는 현상

### 페이지 교체 알고리즘
- FIFO: 먼저 메모리에 적재된 페이지를 먼저 교체하는 기법
- OPT: X
- LRU: 가장 오랫동안 사용되지 않은 페이지를 교체
- LFU: 사용빈도가 가장 적은
- NUR: 참조 비트와 변형 비트를 사용
- SCR: FIFO의 단점을 보완

## 프로세스

### 프로세스
- 실행중인 프로그램
- 하나이상의 스레드를 가진다
- 프로세스 영역
    - 코드영역: 코드 저장
    - 데이터 영역: 전역 변수, 정적 변수
    - 스택 영역: 지역변수
    - 힙 영역: 동적 메모리 할당

### 프로세스 상태 전이
- 생성
- 준비 -> (DISPATCH) -> 실행
- 실행
- 대기
- 종료

### PCB
- 운영체제가 프로세스 정보를 저장하는 공간

### 문맥 교환
- 다른 프로세스가 CPU를 사용하도록 전환하는 과정

### 스케줄링 기법
- 선점형 스케줄링
    - 실행중인 프로세스로부터 CPU를 강제로 빼앗을수 있는 방식
- 비점형 스케줄링
    - 프로세스가 CPU를 점윶우이라면 이를빼앗을 수 없는 방식
- 기아현상과 에이징 기법
    - 기아현상: 우선순위가 낮은 프로세스가 무한정 대기하는 현상
    - 에이징 기법: 기아현상을 해결하기 위한 기법

### 선점형 스케줄링
- Round Robin: Time Slice를 할당
- SRT: 실행시간이 짧은 프로세스를 먼저 수행
- MLQ: 큐에 우선순위를 부여하는 기법
- MLFQ: 큐에 시간 할당량을 부여하는 기법

### 비선점형 스케줄링
- FCFS: 먼저 도착한 프로세스를 먼저 수행하는 기법
- SJF: 실행시간이 짧은 프로세스를 먼저 실행
- HRN: (대기시간+실행시간)/ 실행시간
- 우선순위: 프로세스에 우선순위를 부여
- 기한부: 일정 시간 안에 완료하는 기법

## 병행 프로세스와 교착 상태

### 병행 프로세스
- 두개 이상의 프로세스가 동시에 존재하며 실행 상태에 있는것
- 병행 프로세스 문제 해결책
    - 임계 구역: 한번에 하나의 프로세스만 접근 가능하도록 지정
    - 상호배제: 공유 자원을 사용중일때 다른 접근을 막음
    - 동기화 기법: 스레드들 간의 작업 순서를 조정

### 교착상태
- 자원을 점유한 상태에서 다른 프로세스의 자원을 요구하며 무한정 대기하는 현상
- 발생조건: 상호배제, 점유 및 대기, 비선점, 환형대기
- 해결방법: 예방기법, 회피 기법, 발견 기법, 회복기법

## 스토리지, 환경변수, 로그파일

### 스토리지
- 데이터를 저장하는 저장소
- 종류
    - DAS: 직접 연결
    - NAS: LAN을 통해 서버와 연결
    - SAN: 파이버 채널 스위치를 통해 연결

### RAID
- 구성
    - 스트라이핑: 데이터를 라운드로빙 방식으로 분산 저장
    - 미러링: 데이터를 동일하게 복제하여 저장
- 형태
    - RAID-0: 스트라이핑 사용
    - RAID-1: 미러링 사용
    - RAID-2: 해밍 코드를 사용하여 오류 정정
    - 3: 한 디스크를 페리티 정보 저장용으로 사용/ 바이트 단위
    - 4: 데이터를 블록 단위로 분산 저장
    - 5: 각 디스크에 패리티 정보 포함
    - 6: 두개의 패리티 정보를 디스크에 분산 저장

### 환경변수
- env, set, printenv, export

### 로그파일
- 시스템의 기록을 담고 있는 데이터
- wtmp(전체로그인), utmp(현재 로그인 사용자), btmp(로그인 실패)
