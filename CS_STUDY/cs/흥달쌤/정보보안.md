# 정보보안

## SW개발 보안 설계

### 정보보안 요소
- 기밀성: 인가된 사용자만 접근
- 무결성
- 가용성
- 인증
- 부인방지

### 정보보안 AAA
- 인증: 신원확인
- 인가: 권한허용
- 계정관리: 사용 정보 수집및 과금

### 인증제도
- ISMS: 정보보호 관리체계
- PIMS: 개인정보
- ISMS-P: 두개 포함
- ITSEC: 유럽 평가
- TCSEC: 미국 평가
- CC: 평과 결과 통합

### Secure SDLC방법론
- CLASP: SDLC 초기 단계 보안
- MS-SDL: 마이크로소프트가 개발
- Seven Touchpoints: 보안의 모범 사례를 SDLC에 통합

### 시큐어 코딩
- OWASP: 웹 애플리케이션 보안 프로젝트
- 시큐어 코딩 가이드
    - 입력 데이터 검증 및 표현
    - 보안 기능
    - 시간 및 상태
    - 에러 처리
    - 코드 오류
    - 캡슐화
    - API 오용

### 암호 알고리즘 용어
- 평문
- 암호문
- 암호화
- 복호화
- 전자서명
- 양방향 암호화
- 단방향 암호화

### 블록 대칭 키 암호 알고리즘
- DES: 56, Feistel
- 3-DES: 112, DES 3번 적용
- AES: 128/192/256, SPN구조
- SEED: 128, 한국에서 개발한 표준 알고리즘
- ARIA: 128/192/256, AES와 유사
- IDEA: 128, 스위스 개발
- LEA: 128/192/256, 경량 환경에 적합
- SKIPJACK: 80, 미국에서 개발

### 스트림 암호 알고리즘
- LSFR
- RC4
- A5

### 비대칭 키 알고리즘
- 소인수 분해 기반
    - RSA: 가장 대표적인 공개키 암호 알고리즘
    - RABIN
- 이산 대수
    - 디피 헬만
    - DSA
    - ELGAMAL
- 타원 곡선
    - ECC

### 해시함수 특성
- 역상 저항성: 원래 값 유추되면 안됨 
- 제2역상 저항성: 같은 해시 값을 가지는 다른 입력값을 가지는것은 불가
- 충돌 저항성: 서로 다른 두개의 입력이 같은 해시값을 갖도록 찾는것

### 해시함수 종류
- MD5
- SHA
- HAS-160

### 해시 함수의 결점
- 무차별 대입 공격
    - 모든 가능한 문자열을 대입하여 암호 해독
- 레인보우 테이블 공격
    - 미리 계산된 해시 값 테이블을 이용해 비밀번호를 역추적하는 방식
    - 솔팅: 데이터에 임의의 값을 추가하여 해시 값을 생성

### 인증유형
- 지식 기반 인증: 사용자가 기억하고 있는 정보
- 소유 기반 인증: 소유한 물건을 이용
- 생체 기반 인증: 신체적 또는 행동 특징
- 행위 기반 인증: 사용자의 행동
- 위치 기반 인증: 인증을 시도하는 위치

### 인증방식
- 계정 정보를 요청 헤더에 넣는 방식: 매 요청마다 계정정보를 포함
- 쿠키/세션: 서버에서 세션을 유지하고 클라이언트는 쿠키를 사용
- 토큰기반 인증방식: 서버 상태를 저장하지 않고 토큰 사용
- OAuth: 타사 서비스에 대한 인증을 위임
- SSO: 하나의 인증을 통해 여러 서비스에 접근
- 커버로스: 티켓 기반 인증
- 아이핀: 주민등록번호를 대체하는 온라인 본인인증 수단

### 접근 통제 정책
- 강제적 접근 통제(MAC)
    - 자원의 보안 레벨과 사용자의 보안 취급 인자
- 임의적 접근 통제(DAC)
    - 자원의 소유자가 다른 사용자에게 접근을 허용
- 역할 기반 접근 통제(RBAC)
    - 사용자의 역할을 기준으로 접근 통제

### 접근 통제 모델
- 벨-라파둘라 모델(BLP)
    - 기밀성
- 비바 모델
    - 무결성
- 클락-윌슨 모델: 업무 처리 과정과 트랜잭션의 무결성을 유지하는데 중점
- 만리장성 모델: 이해 충돌을 방지하기 위한 모델

### 보안 취약점
- 관리적 관점: 정보보호 관리체계에 근거하여 취야점 점검
- 기술점 관점: 서버, 네트워크, PC등 기술적인 요소 점검
- 물리적 관점: 시서 ㄹ및 환경점 요소

### 보안관제
- 정보자산을 보호하기 위해 24시간 모니터링
- 침해 사고 발생시 CERT가 대응
- 통합로그 분석 장비
    - ESM: 기업 내 다양한 보안 이벤트 중앙에서 관리
    - SOAR: 보안 이벤트 자동으로 분석
    - SIEM: 실시간 로그 분석

### 보안 솔루션
- 방화벽: 불법적인 접근을 차단
- WAF: 웹 애플리케이션 보호
- 침입 탐지 시스템 IDS: 악의적인 활동을 탐지
- 침입 방지 시스템 IPS: 탐지된 위협을 자동으로 차단
- 데이터 유출 방지 DLP: 데이터의 외부 유출 방지
- 가상사설 통신망(VPN): 
- NAC: 네트워크에 접속하는 장치의 접근을 제어
- Sandbox: 의심스러운 파일을 안전한 환경에서 실행
- FDS: 전자 금융 거래에서 발생하는 이상 거래탐지
- Proxy Server: 사용자의 인터넷 요청을 중계하여 보안 강화

### 방화벽 시스템 구축 유형
- 스크리닝 라우터: 패킷 허용/거부 결정
- 베스천 호스트: 접근 제어, 프록시 기능, 로깅 등을 수행
- 듀얼 홈드 호스트: 두개의 네트워크 인터페이스 가짐
- 스크린드 호스트: 스크리닝 라우터와 베스천 호스트 조합

### 보안 프로토콜
- SSH: 22번 포트 사용
- SSL: 웹 브라우저와 웹 서버 간 안전한 데이터 전송. 443번 포트
- TLS: 전송 계층 보안을 제공하는 프로토콜
- IPSec: 네트워크 계층의 보안을 제공하는 프로토콜
    - 전송모드, 터널 모드
    - AH, ESP
- S-HTTP: HTTP의 보안 확장판
- RadSec: RADIUS 어쩌구

### 고가용성
- 정보 시스템이 오랜 기간 지속적으로 정상적으로 운영 될 수 있는 능력
- 중복성을 통해 고가용성을 실현

### DOS
- 스머프어택: IP, ICMP 특성
- Ping Of Death: 정상 크기 이상의 ICMP 패킷
- Land Attack: 출발지 IP, 목적지 IP 동일
- Teardrop Attack: 재조립 불가하게 플라그먼트 넘버 위조
- SYN, UDP, Ping Flooding

### DDOS 공격
- 트리누, TFN, 슈타첼드라트

### 공격 유형
- 웜: 자가 복제
- 바이러스: 파일에 숨어 이동
- 트로이목마: 위험 요소를 숨김
- 스턱스텟: 물리적 파괴 목적
- 루팅: 루트계정 획득
- 루트킷: 루트 권한을 얻게 해주는 킷
- 혹스: 가짜바이러스
- 스니핑: 도청

- IP Spoofing: ip 주소 위장
- ARP 스프핑: MAC 주소 위장
- DNS 스프핑: DNS 질의 결과를 위조하여 반환
- 파밍: 피싱 사이트로 유도
- 타이포스쿼팅: URL 실수 이용
- 스미싱: 문자 메세지를 이용한 피싱
- QSHING: QR코드를 이용한 금융 범죄
- 포트 스캐닝: 열려있는 포트 사용

- 세션 하이재킹: 세션을 빼앗는 공격
- 버퍼 오버플로우: 버퍼를 초과하여 메모리 침범
- Format String Attack: 문자열 출력 포맥 이용하여 공격
- SQL injection: SQL 명령 삽입
- XSS: 자바스크립트 삽입
- CSRF: 공격자가 의도한 행위를 요청
- 백도어: 정상적인 인증 절차 없이 시스템에 접근
- Password Cracking: 도구를 이용한 비밀번호 확인

- 레인보우테이블: 해시 함수의 취약점 이용
- APT: 지속적인 공격
- Nucking: 대량의 패킷으로 접속을 끊음
- 부채널 공격: 암호 알고리즘을 대상으로 한 공격
- Brute Force: 무차별 대입 공격
- 딕셔너리 어택: 사전에 정의된 패스워드패턴 이용
- 키 로거 어택: 키보드 입력 가로챔
- 스파이웨어: 사용자 정보 수집

- 애드웨어: 광고
- 트랙웨어: 사용자 작업 추적
- 랜섬웨어: 시스템 접근을 제한하고 목밧을 요구
- 제로데이 공격: 아직 알려지지 않은 취약점 이용
- 사회공학: 사람의 신뢰 기반
- 에빌트윈어택: 가자 와이파이 ap 이용

- 블루버그: 블루투스 연결 취약점 이용
- 블루스나프: 파일에 접근
- 블루프린팅: 장비 탐색
- 블루재킹: 익명 메시지 전송
- 스위치 제이밍: 스위치 혼란
- 허니팟: 공격자 유도
- 블루킵: 원격 데스크톱 서비스 취약점 이용
- 인포데믹스: 소문으로 인한 대중의 두려움 증폭

- 살라미: 조금씩 빼내는 기법
- 다크데이터: 저장만 되어있는 데이터
- 킬 스위치: 원격 삭제
- 트러스트존: 독립적인 보안 구역
