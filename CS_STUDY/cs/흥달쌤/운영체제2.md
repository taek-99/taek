# 운영체제

## 시스템 소프트웨어
- 감시
- 작업
- 데이터 관리

## 운영체제 운용 기법
- 일괄 처리
- 실시간 처리
- 다중 프로그래밍 시스템
- 시분할
- 다중처리
- 다중 모드

## 파일 디스크립터
- 프로세스가 파일에 접근할 때 사용하는 구조

## 유낙스 구성
- 커널
- 쉘
- 유틸리티

## 유닉스 파일 시스템
- 부트 블록
- 슈퍼 블록
- i-node 블록
- 데이터 블록

## 퍼미션
- 권한별: 751
- chmod
- usmask
- chown

## 기억 장치 관리 전략
- 반입 전략: 요구 반입, 예상반입
- 배치 전략: 최초, 최적, 최악
- 교체 전략: FIFO, OPT, LRU, LFU, NUR, SCR

## 단편화
- 주기억 장치에 프로그램 할당하고 반납하는 과정에서 빈공간
- 종류
    - 내부
    - 외부
- 단편화 해결
    - 통합
    - 압축
    - 재배치 기법

## 가상기억 장치
- 보조기억장치의 일부를 주기억장치처럼 사용하는 기법
- 블록 분할 방법
    - 페이징 기법: 같은 크기로 분할/ 내부 단편화
    - 세그멘테이션 기법: 가변 크기로 분할/ 외부 단편화
- 기타관리사항
    - 페이지부재
    - 지역성
    - 워팅셋
    - 스레싱

## 프로세스
- 실행중인 프로그램
- 하나 이상의 스레드를 가짐
- 프로세스 영역
    - 코드 영역: 코드 저장
    - 데이터 영역: 전역, 정적
    - 스택 영역: 지역
    - 힙 영역: 동적

## PCB
- 운영체제가 프로세스 정보를 저장하는 공간

## 스케줄링 기법
- 선점형
    - RR, SRT, MLQ, MLFQ
- 비선점형
    - FCFS, SJF, HRN, 우선순위, 기한부
- 기아현상: 우선순위가 낮은 프로스세스가 무한정 대기
- 에이징: 기아현상을 해결하기 위한 기법

## 병행 프로세스
- 두개 이상의 프로세스가 동시 실행 상태
- 프로세스 문제 해결책
    - 임계구역: 한 번에 하나의 프로세스만 접근 가능하도록
    - 상호 배제: 공유 자원 사용시 다른 접근 못하도록
    - 동기화 기법: 스레드들 간의 작업순서 조정

## 교착 상태
- 자원을 점유한 상태에서 다른 프로세스의 자원 요구
- 발생 조건
    - 상호 배제, 점유 및 대기, 비선점, 환형 대기
- 해결 방법
    - 예방, 회피, 발견, 회복

## 스토리지
- 데이터를 저장하는 저장소
- 종류
    - DAS: 직접 연결
    - NAS: LAN을 통해 서버와 연결
    - SAN: 파이버 채널 스위치를 통해 연결

## RAID
- 구성
    - 스트라이핑
    - 미러링
- 형태
    - RAID-0: 스트라이핑
    - RAID-1: 미러링
    - RAID-2: 헤밍코드
    - RAID-3: 패리티정보 저장
    - RAID-4: RAID-3과 유사
    - RAID-5: 각 디스크에 패리티 정보 포함
    - RAID-6: 두개의 패리티 정보를 디스크에 분산 저장
