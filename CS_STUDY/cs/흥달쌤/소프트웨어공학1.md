### UNL 관계

- 의존 관계: 짧은 시간만 사용

- 집합-합성 관계: 부분 객체는 의존성

### UML 다이어그램
- 구조 다이어그램
    - 클래스: 시스템 구조
    - 객체: 객체 간의 관계
    - 컴포넌트: 컴포넌트간의 관계
    - 배치: 물리적인 노드와 통신 경로
    - 복합체 구조: 구체적인 수준의 실행 구조
    - 패키지 다이어그램: 논리적으로 묶인 요소를 그룹화

- 행위 다이어그램
    - 유스케이스: 사용자와 기능 간의 상호작용
    - 순차: 시간 순서
    - 커뮤니케이션: 객체간의 메시지 전달 방식과 순서
    - 상태: 객체의 상태 변화
    - 활동: 업무의 흐름 표현, 유스케이스의 구체적인 흐름
    - 상호작용: 객체간의 상호작용
    - 타이밍: 시스템 간의 신호변화

- 유스케이스: 시스템 동작 방식 기술

## 프로그래밍 기초 개념

### 변수명 표기법
- 카멜: 첫 단어 제외하고 각 단어의 첫글자 대문자
- 파스칼: 모든 단어의 첫글자를 대문자로 표기
- 스네이크: 모든 단어를 소문자로 표기하고 단어 연결시 _사용
- 헝가리안: 변수의 자료형이나 특성을 접두사로 사용
- 케밥: 모든 단어를 소문자로 표기하고, 하이픈으로 연결

### 서버 환경 구축
- 웹서버: 정적 파일
- 웹 애플리케이션 서버(WAS): 동적인 웹 서비스 제공
- 데이터 베이스 서버: 데이터 저장 및 관리
- 파일 서버: 파일을 저장하고 고유
- 로드 밸런서: 네트워크 요청 분배
- CDN: 대용량 콘텐츠 제공

### 개발 소프트웨어
- 요구사항 관리 도구
- 설계/ 모델링 도구
- 구현도구
- 테스트 도구
- 형상관리 도구
- 협업 도구
- 배포 도구

### 형상관리
- 변경관리: 소스코드의 변경 사항을 관리
- 버전관리: 체크인/ 체크아웃, 릴리즈, 퍼블리이싱
- 형상관리: 프로젝트 진행 상황, 빌드, 릴리즈까지 관리

### 형상관리 절차
- 형상 식별: 관리해야할 항목을 구분
- 형상 통제: 변경 요청을 검토하고 형상통제 위원회의 승인을 거처 현재의 기준선에 반영
- 형상 감사: 변경에 대한 검토
- 형상 기록: 변경 사항과 처리 과정을 기록

 ## 모듈 구현

 ### 결합도
 - 자료 결합도(DATA): 값 전달
 - 스탬프 결합도(STAMP): 배열 등을 전달
 - 제어 결합도(Control): 제어 요소 전달
 - 외부 결합도(External): 다른 모듈 변수 사용
 - 공통 결합도(Common): 전역 변수 사용
 - 내용 결합도(Content): 다른 모듈 기능 이용


 ### 응집도
 - 기능적 응집도(Functional): 단일한 목적 수행
 - 순차적 응집도(Sequential): 출력값을 입력값으로 사용
 - 통신적 응집도(Communication): 동일한 입력, 출력
 - 절차적 응집도(Procedural): 순차적 수행
 - 시간적 응집도(Temporal): 같은 시간 기능 수행
 - 논리적 응집도(Logical): 유사항 성격
 - 우연적 응집도(Coincidental): 연관관계 없음
