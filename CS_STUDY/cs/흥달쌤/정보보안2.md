## 공격 유형
- 스턱스텟: 물리적 파괴
- 루팅: 루트계정
- 루트킷: 루트 권한 얻음
- 혹스: 가짜 바이러스
- 스니핑: 도청

- ip 스푸핑: ip 주소 위장
- arp 스푸핑: mac 주소 위장
- dns 스푸핑: dns 질의 결과 위조
- 파밍: 피싱 사이트 유도
- 타이포스쿼핑: url 실수 이용
- 스미싱: 문자메시지 이용
- 큐싱: QR코드 이용
- 포트 스캐닝: 열려있는 포트 탐색

- 세션 하이재킹: 세션 탈취
- 버퍼 오버플로: 버퍼 초과
- Format string attack: 문자열 출력 포맷
- sql 인젝션: sql 명령 삽입
- xss: 자바스크리브 삽입
- csrf: 공격자가 의도한 행위 요청
- backdoor: 정상적인 인증 절차 없음
- 패스워드 크래킹: 도구를 이용한

- 래인보우 테이블: 해시 함수 취약점
- apt: 지속적인
- nucking: 대량의 패킷 끊음
- 부채널 공격: 암호 알고리즘 대상 공격
- 딕셔너리 어택: 사전에 정의되 패스워드 패턴 이용
- key logger attack: 키보드 입력 가로챔
- 스파이웨어: 사용자 정보 수집

- 에드위어: 광고
- 제로데이: 아직 알려지지 않은 취약점
- 사회공학: 사람의 신뢰 기반
- 이블트윈어택: 가짜 와이파이
