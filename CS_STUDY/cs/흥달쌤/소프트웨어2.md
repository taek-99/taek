

## 인터페이스 구현 검증 도구
- xunit: 다양한 언어
- STAFl 컴포넌트 재사용
- 피트니스: 웹 기반
- 세레니움: 웹 애플리케이션
- watir: 루비 사용

## 인터페이스 보안
- 네트워크 영역: IPsec, SSL, S-HTTP
- 애플리케이션 영역: 시큐어 코딩
- DB 영역: 암호화 API, PLUGIN, TDE

## EAI
- 기업내 다양한 플랫폼 연결
- 구축 유형
    - Point-to-Point: 직접 연결
    - Hub & Spoke: 중앙허브를 통해 연결
    - Message Bus: 미들웨어를 사용한 메시지 전달
    - Hybrid: 합치넉

## 소프트웨어 테스트
- 결함을 발견하기 위한 절차와 행위
- 테스트의 필요성
    - 오류 발견 관점
    - 오류 예방 관점
    - 품질 향상 관점

## 블랙박스 테스트
- 동등값 분할
- 경계값 분석
- 원인 효과 그래프: 입력 데이터 간의 관계와 출력
- 오류 예측: 과거의 경험
- 비교 검사: 여러 버전
- 상태전이: 상태를 변화시키는 

## 테스트 목적
- 회복: 고의로 실패
- 안전: 보안
- 강도: 과부하
- 성능: 응답시간, 처리량, 반응속도
- 구조: 소스코드의 복잡도를 평가
- 회귀: 변경 코드에 대한 새로운 
- 병행: 변경된 시스템과 기존 시스템에 동일한 데이터
- A/B: 기존 서비스 
- 스모크: 테스트를 테스트

### 코드 커버리지
- 조건/결정 커버리지: 결정 포인트 T/F
- 변경/조건 결정 커버리지: 모든 결정 포인트 내의 조건식
- 다중: 모든 조합

## 결함 관리
- 에러 발견
- 에러 등록
- 에러 분석
- 결함 확정
- 결함 할당
- 결함 조치
- 결함 조치 검토 및 승인

## 테스트 장치
- 테스트 케이스: 입력, 실행조건, 기대결과
- 테스트 슈트: 케이스의 집합
- 테스트 스크립트: 테스트 설명서
- 목 오브젝트: 조건부로 상황에 예정된 행위

## DRM
- 디지털 콘텐츠의 불법 사용을 제한하고, 승인된 사용자에게만 콘텐츠 사용 허용
- 구성
    - 콘텐츠 제공자
    - 콘텐츠 분배자
    - 패키저: 메타데이터와 함께 묶음
    - 보안 컨테이너: 안전한 유통
    - DRM 컨트롤러: 콘텐츠의 이용권한을통제
    - 클리어링 하우스: 키 관리
