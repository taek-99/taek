# 데이터베이스

## 데이터베이스 정의
- 공유: 여러사람이 공통으로 사용
- 저장: 저장
- 통합: 중복을 최소화
- 운영: 조직의 목적 달성

## 스키마
- 외부: 사용자
- 개념: 전체적인구조, 제약조건
- 내부: 어케 저장되어 있는지

## 데이터 독립성
- 논리적: 개념이 바꿔도 외부에 영향 x
- 물리적: 내부가 바꿔도 외부 및 개념에 영향 x

## DBMS의 종류
- 계층형: 트리, 다대다
- 네트워크형: 게층형 모델의 담점 보완, 다대다 가능, CODASYL
- 관계형: 행과열
- 객체지ㅑㅇ혀
- NoSQL

## 데이터베이스 설계 단계
- 요규
- 개념: E-R
- 논리: 정규화, 목표 DBMS설계, 트랜잭션
- 물리: 특정 DBMS설계
- 구현

## 데이터 모델 표시 요소
- 구조: 데이터 구조와 관계
- 연산
- 제약조건

## E-R다이어그램
- 사각형: 개체
- 마룸모: 관계
- 타원: 속성
- 밑줄 타원: 기본키 속성
- 이중타원: 다중값 속성
- 선링크: 연결

## 이상현상
- 삽입
- 삭제
- 갱신

## 함수적 종속
- 어떤 속성 집합이 다른 속성 집합의 값을 유일하게 결정

## 데이터베이스 이중화
- 장애에 대비하여 동일한 데이터베이스를 중복하여 관리
- 분류
    - Eager기법
    - Lazy 기법

## 데이터베이스 백업
- 전체 백업: 모든 데이터 백업
- 증분 백업: 변경/추가된 데이터만 백업
- 차등 백업: 모든 변경/추가된 데이터 
- 합성 백업: 전체와 증분을 합치는거

## RTO/ RPO
- 복구 시간 목표: RTO
- 복구 목표 시간: RPO

## 데이터베이스 암호화
- API방식: 앱에서 수행
- Plug in방식: 제품 사는거
- TDE 방식: DBMS내부의 기본 모듈로 수행

## 파티셔닝
- 데이터베이스의 특정 부분을 여러 섹션으로 분할
- 분할 기준
    - 범위 분할
    - 목록 분할
    - 해시 분할
    - 라운드로빈 분할
    - 합성 분할

## 클러스터
- 자주 사용되는 테이블의 데이터를 디스크 상 동일한 위치 저장

## 인덱스
- 데이터베이스 테이블 검색 속도 향상을 위한 자료구조
- 종류
    - 틀러스터
    - 넌클러스터
    - 밀집
    - 희소

## 뷰
- 기본 테이블에서 유도된 이름이 있는 가상 테이블

## 시스템 카랄로그
- 데이터 개체들에 대한 정보를 저장한 시스템 테이블

## 절차형 SQL
- 저장프로시저
- 트리거
- 사용자 정의 함수

## 관계 데이터 릴레이션의 구조
- 속성: 열
- 튜플: 행
- 도메인: 속성의 범위
- 차수: 속성의 개수
- 카디널리티: 튜플의 개수

## 릴리이션의 구성
- 릴레이션 스키마

## 관계 대수
- 순수 관계
    - SELECT
    - PROJECT
    - JOIN
    - DIVISION
- 일반 집합
    - 합, 교, 차, 교차곱

## 관계 해석
- 원하는 정보가 무엇인지 정의 비절차적

## 데이터베이스 무결성
- 고유

- 릴레이션

    - 비용기반: 객체 통계정보와 시스템 통계정보
